# SnowDesktop control

## Capabilities

Use SnowDesktop on Windows to set up or organize the desktop, make apps and files easier to reach, change its appearance and interaction, configure Dock, the status bar, Quick Navigation and widgets, or record and replay SnowDesktop interactions. The Skill operates the running app through local IPC.

Read [Understand SnowDesktop](CAPABILITIES.md) when choosing components or answering product questions. It covers what the app offers and how each of the five desktop storage components works.
