# Desktop layout guidance

Use this guidance for organizing the desktop, moving components or rearranging a layout.

For a first-time setup, use [the task guidance](../TASK.md) to understand which activities or materials should be easiest to reach. If browsing a working folder directly from the desktop would change the arrangement and the user has yet to choose, ask about it in a separate turn after resolving that priority. Explain that the files stay in their original folder and ask for the path after the user opts in. For a scoped edit to an existing desktop, identify the affected items, components and screens and carry forward the user's layout and preferences.

Preview substantial placement changes before applying them and explain how the user will reach their usual apps and files. Read back the affected positions, membership, active tabs and save status. Check the finished composition at normal desktop scale against a usable view or the user's observation. Mark the visual result as awaiting confirmation when that evidence is unavailable. After a first-time setup, you can introduce one optional feature relevant to the user's goal.

## Whole-screen layout

Start with the wallpaper and usable grid on each screen being rearranged. Use a desktop view or wallpaper reference to identify the focal area, where labels will read clearly, and which area should stay open. An obscured view gives only partial evidence. If you cannot see enough of the wallpaper to guide placement, ask which area the user wants to keep visible and treat the visual fit as provisional.

Choose one edge for the panels or two adjacent edges for an L-shaped arrangement. Let the wallpaper and the user's everyday activities guide the choice. Use the outermost usable grid positions along the chosen edges to align neighboring panels. Fit the intended first visible rows and leave room reserved for Dock, the status bar or the Windows taskbar.

Give categories the user often needs to see or access together their own Collection panels where useful. Let categories used in turn share space in a Collection Group. Both forms can share a layout. Components shown as icons share the desktop grid with loose items. Lay out the items that remain loose as part of the same composition. A compact vertical run starting at the upper left is a familiar Windows starting point, adjusted to the user's habits and available space. Check the final positions in the preview, close accidental holes within each run, and keep deliberate spacing between groups that need visual separation. Compatible components can also be reached through Dock.

Keep working plans and layout references in the task workspace, outside SnowDesktop's runtime data directory.
