MiSans Regular OTF and HarmonyOS Sans SC Regular TTF total 14,830,464 bytes (14.1 MiB).
Font weight settings remain requests to the text renderer; with only Regular
faces installed, weight variation is limited to the renderer's available matching
or synthesis. Users can import original variable fonts or multi-weight packages
for more precise weight variation. Missing glyphs fall back to system fonts.
