# Settings icon assets

The transparent 192 x 192 PNG files in this directory are composed from
Microsoft Fluent System Icons Regular and Filled glyphs. They use the same
upstream revision as SnowDesktop's embedded Regular font:
`21d5d02f724be2aaf586564775fff73a18a76eb6`.

- Upstream: <https://github.com/microsoft/fluentui-system-icons>
- License: MIT; see `third_party/fluentui-system-icons/LICENSE`.
- The deprecated upstream Color variants are not used.
- The Filled font was used only to render these derived bitmap assets and is
  not redistributed.
