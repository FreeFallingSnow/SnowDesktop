# Icon theme gallery artwork

The gallery uses nine SVGs in a 3 by 3 arrangement. Only the browser sample has
an application backplate. The other eight samples have transparent backgrounds.
All glyphs retain the pinned Microsoft Fluent System Icons 24 px Filled and
Regular paths at `21d5d02f724be2aaf586564775fff73a18a76eb6`.
License: [MIT](../../../third_party/fluentui-system-icons/LICENSE).

| Sample | Artwork |
| --- | --- |
| Browser | `assets/settings/icons/preview-browser.svg`, existing app tile |
| Folder | `assets/settings/icons/preview-folder.svg` |
| Mail | `mail.svg`, paths from `assets/settings/icons/preview-mail.svg` |
| Media | `media.svg`, upstream `Play 24 Filled + Regular` |
| Terminal | `terminal.svg`, paths from `assets/settings/icons/preview-terminal.svg` |
| Trash | `assets/settings/icons/preview-trash.svg` |
| Settings | `assets/settings/icons/general.svg` |
| Calendar | `assets/settings/icons/calendar.svg` |
| Apps | `assets/settings/icons/widgets.svg` |

Mail and terminal remove the decorative app tile from the existing illustrations.
Media uses the upstream Play glyph without the enclosing Play Circle plate.
All three use the original 24 px viewBox and preview colors for visibility on
light and dark material. They do not change the desktop layout illustration.
