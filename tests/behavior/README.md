# 宿主行为测试

`core_interactions_tests.cpp` 是共用驱动，复用应用编译出的宿主对象。各场景拥有临时数据目录和消息窗口，不启动桌面宿主；文件操作、异步完成、模型刷新与布局保存使用生产实现。

## 历史拖放回归

以下场景按反复出现的历史错误建立。`drag_access.inc` 只提供私有入口适配，`drag_contracts.inc` 提供受控来源、场景输入和业务断言。

| CTest 名称 | 历史依据 | 实际执行与验收 |
| --- | --- | --- |
| `behavior_drag-source` | `fbd6ca6bb509`、`2fe313714e42` | 集合捕获、容器重建和取消：不可见选中项仍在载荷中；更换选择及重排后，原始身份、顺序与源文件保持正确。 |
| `behavior_drag-files` | `d325b085b520` | 原生 Shell 数据对象经 OLE 适配器、工作线程及宿主完成消息执行异步复制；核对源生命周期、实际字节和目标集合归属。另执行真实移动，核对实际输出与完成结果；卷支持时使用原生短路径。 |
| `behavior_drag-batches` | `f91bb2c86790`、`8300848df0cf` | 两笔真实文件请求在刷新前完成；核对独立落点均被保留，并在真实模型刷新后进入各自集合，文件内容及无关源不变。 |
| `behavior_drag-partial` | `62cd28d4006f` | 一笔真实快捷方式批次先成功、后失败；核对成功集合，释放生产临时资源后保留被引用内容，只删除未使用内容，成功链接仍可解析。 |
| `behavior_drag-release` | `66421876e655` | 私有输入经真实目标解析、释放、位置提交、延迟保存和磁盘重载；核对最终格位，后续取消不改变位置及文件内容。 |
| `behavior_drag-popup` | 2026-11-01 弹窗间拖拽被关闭流程取消；2026-11-03 左右 padding 落点错误、远处空白缺少落点预览的反馈 | 调用真实组件和弹窗命中入口，核对固定/滚动网格、列表及集合/文件夹弹窗两侧 padding 的最近插入索引、远处空白的可绘制目标，以及标题区不产生条目插入槽位；独立原生窗口调用共用弹窗关闭、捕获变更和取消消息路径，核对桌面/集合来源、选择与载荷存活；真实 DComp 表面重复创建/结束 32 次后释放，保留一个预览窗口；核对提示、虚影、弹窗的层级及重复同步稳定性。取消消息为等价负向边界，不代表完整鼠标拖拽复现。 |

运行这些条目：

```bat
scripts\test.bat name "^behavior_drag-"
```

每个异步条件通过现有消息循环等待实际完成，超时附带最后状态。失败依据是载荷、文件、归属或保存结果，不能以返回“接受”代替提交成功。首次失败和补验结果分别保留，验证证据按[构建与验证规则](../../.agents/rules/validation.md#缺陷证据)记录。

受控来源转发真实 Shell 数据对象，仅控制外部异步来源的生命周期；私有输入只发送给测试拥有的消息窗口。部分失败场景直接提交生产文件请求并使用生产资源释放逻辑，未经过完整 OLE 入口。驱动未运行宿主主循环，也不覆盖完整宿主析构。

这里没有覆盖真实跨应用拖出、鼠标跟随、闪烁、多屏 DPI 与桌面视觉反馈；这些仍需用户实测。短路径不可用时，移动场景仍核对实际文件结果，并输出 `short-alias=0` 标明别名分支未覆盖。

后续根据真实回归扩展已有场景，遵守[长期测试准入](../../AGENTS.md#临时验证与长期测试准入)，补齐新风险的生产路径与原错误失败证据；已删除测试和旧矩阵不计入现有覆盖。
