# 本地化引用门禁

`localization_contract` 默认拒绝未引用的全局语言键和组件包语言键。`--strict-unused` 仅保留命令兼容，不改变结果；不维护历史无用键基线或按前缀放行的清单。

引用检查同时覆盖：

- C++ 和 Lua 的直接翻译调用，以及条件表达式中真正作为键的分支；比较用的状态字符串不算键。
- 被消费的表、具名 Lua 表字段及跨文件常量中的完整键。注释、独立字符串及可识别的无消费者常量不能保活翻译。
- CMake 生成的启动器消息；有限动态键从实际控件调用、预设列表、星期和有效投影模式推导；Workshop Manager 按其生产适配器的英文值映射识别引用。
- 组件 manifest 的名称、说明、标题和预览存储字段，以及组件包内 Lua 文件的间接引用。包与包之间不相互保活键。

新增动态生成器时，将生成域和真实消费端一起纳入检查，并提供有效引用、删除消费者、新增未引用键的正负样本。不能因为某个目录或键前缀存在就保留整个语言库。此扫描提供静态引用证据，不证明任意 C++/Lua 程序的完整运行可达性。

`TestReferenceAuditContracts` 保留直接调用、表引用、Lua 具名字段、注释、无消费者常量、同名局部变量、跨作用域消费端、CMake 注释和数字分隔符的回归。`TestDefaultUnusedGate` 在常规测试内直接向真实全局门禁和组件包门禁提供已知无用键，明确禁用旧严格参数，要求各产生一次对应失败；把任一门禁降回只告警时，该自检必须失败。
