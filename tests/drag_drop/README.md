# SnowDesktop 核心拖放行为矩阵

本文件是测试模型的维护入口。增加类型、状态、动作、修饰或传输方式时，先更新对应因素域、约束和独立预期，再接入测试。以下分析中的“待定义”和“未接入”均为覆盖缺口，不计为通过。

扩展门禁随 `slot_contract_matrix` 编译：`slot_drop_expectations.h` 分别登记原生组件、surface 和 payload 的独立取值及预期；新增原生组件只补生产注册表仍不能通过。`matrix_domain_review.h` 对动作、来源类别、目标类别、落点类别、Dock 条目、命中区域、有向关系及路由使用无默认分支的穷举审阅，遗漏新枚举值直接报错。它是矩阵域变更门禁，不把“已列出某值”当作该值的行为已经覆盖。任意新增布尔状态、动态策略及修饰键组合仍须按本文件和仓库规则扩展因素、约束与生产执行检查，当前门禁不能自动识别任意 C++ 字段的业务意义。

门禁对照分别添加未登记动作、添加合法生产注册但缺少独立预期的新组件，均在预定的编译门禁处失败；将既有集合改登记为映射槽位仍能编译生产注册表，但原生分类断言退出 1。候选退出 0。前两项是预期的 schema 拦截，不计作用户缺陷的运行回归失败；原始隔离探测混用头文件路径导致的编译错误另存，未作为门禁有效证据。

Dock 独立事务夹具按 U07 检查普通固定与 Ctrl 映射的桌面归属差异，按 B09 检查给定插入边界的字面顺序，按 B19 检查映射移除仅删除 Dock 引用。首次原生诊断误复制仅可移动的桌面项导致编译错误；随后 C++20 `u8path` 弃用警告改用 UTF-8 路径构造，原日志保留。无警告编译后的初版在弹出列位置的精确浮点比较处退出 1：逐字段诊断确认其他配置一致，归一化位置写回后差值小于 0.000001。跟进按低于可见像素的百万分之一宽度比较列位置，其余字段仍精确比较；候选 Dock 与异步模式均退出 0。这项夹具比较错误及原失败均保留，未计作产品缺陷。

## 1. 模型与预期依据

矩阵由情境参数、适用约束、行为契约、事件序列和验收输出组成。来源到目标是矩阵中的一组参数，不能独立代表完整用例。

本模型登记 **101 个情境字段**：来源和目标各 24 个端点字段，共 48 个；选择 6 个、关系 4 个、手势 3 个、命中 8 个、策略 16 个、传输 5 个、环境 6 个、完成条件 5 个，共 53 个。字段含条件适用项和序列输入，101 不是无约束笛卡尔积的维数。相对初始 83 项，补入两端的页面命名、其余内容、映射角色、桌面项大图标配置和页列/行数，以及有效显示器集合、配置顺序、目标页记录状态、整页占用、指针位移方向和规划缓存历史；新增因素不自动计为执行覆盖。

一条完整场景采用以下结构：

```text
场景 = 来源端点 + 目标端点 + 选择结构 + 对象关系 + 手势与菜单
     + 命中位置 + 策略 + 传输方式 + 环境 + 完成条件 + 事件序列
预期 = 接收判断 + 可见反馈 + 操作语义 + 文件变化 + 逻辑归属变化
     + 落点与顺序 + 持久化结果 + 生命周期结果
```

预期来源的优先级为：用户明确需求；仍有实际绑定的菜单、提示和指南；公开 API 或平台协议；对象语义和数据不变量的推导。当前执行代码记录为实现观察，用于比较和定位。

| 依据标记 | 含义 | 对预期的用途 |
| --- | --- | --- |

## 10. 语言键检查纳入改造

用户要求：**确认无用的语言键存在时，默认测试失败。**

改造前的检查主要收集直接字符串调用，全局未引用项默认告警，`--strict-unused` 才失败。当前 [全局绑定收集](/D:/Code/Other/SnowDesktop/tests/localization_contract_tests.cpp:591)、[默认无用键检查](/D:/Code/Other/SnowDesktop/tests/localization_contract_tests.cpp:975) 和 [默认门禁自测](/D:/Code/Other/SnowDesktop/tests/localization_contract_tests.cpp:1393) 已替换该行为：全局与组件无用键在默认调用中都失败。真实有限动态引用和静态分析边界详见 `../localization/README.md`，不能把旧扫描器的限制或原参数语义当作当前结果。

表驱动、条件表达式及返回键的 helper 会产生间接引用。例如 [Dock 提示键选择](/D:/Code/Other/SnowDesktop/src/drag_drop/drag_hint_rules.h:6) 由 [Dock 提示入口](/D:/Code/Other/SnowDesktop/src/core/dock.cpp:3011) 交给 `_LW`，不是该位置的直接字符串调用。某个键另有直接引用不消除这种解析边界。

| 编号 | 改造要求 | 确定失败信号 |
| --- | --- | --- |
| L01 | 全局键、内置组件键及官方组件键分别计算定义与真实引用；默认禁止确认的无用键 | 任一无用键使默认测试非零退出；不能只打印计数告警 |
| L02 | 识别直接、表驱动、条件选择、受约束拼接和声明式数据引用，记录引用位置与到本地化入口的关系 | 有效的间接引用不误报无用；未知解析形态报告覆盖缺口并阻止完整引用审计通过 |
| L03 | 动态引用采用可检查的生产声明/有限取值域，核对声明与实际消费位置 | 声明不存在的取值、缺翻译、过宽前缀、仅为压制失败的无消费者声明均失败 |

| L07 | 建立引用检查本身的正反样本 | 添加无引用键必须失败；有效表驱动/拼接引用应通过；去掉真实消费者后必须失败 |
