# SnowDesktop 核心拖放行为矩阵

本文件维护拖放的情境字段、产品行为约定、独立预期和测试覆盖边界。

## 1. 模型与预期依据

矩阵由情境参数、适用约束、行为契约、事件序列和验收输出组成。来源到目标是矩阵中的一组参数，不能独立代表完整用例。

产品行为约定如下：

| 决策 | 适用情境 | 独立预期与验收边界 |
| --- | --- | --- |
| D01 | 混选组件和文件，所选操作不能处理其中一部分对象 | “处理能处理项目即可”：执行支持的成员，不能因不支持成员而整组拒绝；不支持成员的身份、位置、配置、归属和底层文件保持原状。测试从完整捕获选择开始，逐项对应实际结果，不预先过滤输入或宣称整组成功。组件在 Ctrl/Alt 混选中的边界由 D03 明确；部分处理的反馈文案仍属 Q02 |
| D02 | 容器已按名称、大小或日期等字段自动排序，用户执行有效的手动成员拖动 | “切为手动排序，保留拖后顺序”：成功重排后退出自动排序，按插入语义保留移动成员及其他成员的顺序，刷新、重建与保存重载后保持；拒绝、取消和无有效成员的拖动不得切换排序或改数据。日期表头等禁止手动操作的既有前提仍适用，不由该决定补定 Q07 的比较和分组细节 |
| D03 | 混选普通文件和单图标组件，按 Ctrl 复制或 Alt 创建快捷方式 | “只处理普通文件，组件保持原样”：对所选普通文件执行对应物理复制或创建可解析的快捷方式，原文件保留；所选组件及其子项、成员、位置、配置和原文件不变。没有所选普通文件时不产生文件或目标成员。来源捕获必须保留完整混选，不预先删除组件后绕过过滤链；两类动词分别验收源、实际输出身份、目标归属、可访问位置及刷新/重载。此决定不授予复制组件或创建组件快捷方式的能力 |
| D04 | 外部真实文件同时允许 Move/Copy，无修饰键，拖入桌面或普通原生存储组件 | “同卷默认移动，跨卷默认复制”；多选包含同卷与跨卷来源时“整批复制，保留全部来源”。集合、桌面文件及其组的物理目标为受管桌面目录，映射及其组为原映射目录；判断实际物理卷，不能以组件类型或盘符字符串代替。所有来源与目标同卷才默认移动，其他已明确跨卷批次整批复制。Ctrl/Shift/Alt、Ctrl+Shift 与右键选定动词不受默认规则覆盖；尚未获得路径的异步来源不得在悬停阶段强制渲染，最终动作须在路径可用后兑现。卷身份不可判定的处置仍待用户确认 |
| D05 | Shift 合并同类集合或桌面文件组件 | 目标设置保持不变，去重合并成员后移除来源组件。物理文件、未参与对象及目标稳定身份保持；同身份重复成员只归入一次，完整保存和重载后仍成立。具体合并成员顺序未由此补定 |
| D06 | 成员移出后的组生命周期 | 拖动建成的组剩一个成员自动解组、空组移除；手动创建的组剩一个或为空均保留。转移中的调用栈和拖动上下文存活时不能使对象悬空；原子成员及其内容、设置和文件保留，外层收尾后身份和可访问性正确并持久保存 |
| D07 | 文件直接放到未激活的组标签 | 按命中的标签接收并激活；无插入标记时追加到该子来源末尾，不得用标签序号作为成员插入索引。文件、目标子来源、原有顺序、活动标签及重载分别核对 |
| D08 | 图片、文本、虚拟文件及多格式 URL 内容 | 图片保存为可解码 PNG，文本为 UTF-8，虚拟文件按完整描述批次接收；多格式优先完整文件、图片、URL、文本，虚拟批次缺项时不得退到预览图。网页 URL 建网站快捷方式，直接文件 URL 下载；仅复制并保留来源 |
| D09 | 已有快捷方式再建快捷方式、文件夹快捷方式接收 | 解析到最终目标；文件夹快捷方式按实际目录接收。不得建立指向待清理临时数据的链接 |
| D10 | Dock 跨分区混选与未匹配运行项 | 按对象类型放入对应分区，各分区保持捕获顺序；普通运行图标只有匹配桌面入口才允许固定或映射。资源管理器例外：拖到固定区可创建指向资源管理器本身的入口；拖到文件区仅在识别到当前真实文件夹时固定该目录，优先复用已固定的同目录入口，或唯一桌面入口，否则创建文件夹快捷方式；多个同目录桌面快捷方式仍可固定且不任意移动其中一个。当前目录无法识别时拒绝。新建入口独占 Dock；复用入口保留普通固定/Ctrl 映射规则 |
| D11 | 大图标进入 Dock 或逻辑容器 | 保留大图标配置，容器内按普通跨度显示，返回桌面时恢复原配置；保存、刷新和重载不能丢失配置 |
| D12 | 搜索插入、日期表头、类型排序及标签悬停 | 插入标记对应真实成员，隐藏成员保留相对顺序；有效拖动切手动并在清除搜索后保持完整顺序，无标记追加末尾。日期表头开启时自身成员重排拒绝，搜索不例外。类型排序规则为：升序为“此电脑、回收站等系统项 → 文件夹 → 文件夹快捷方式 → 其他类型”；其他类型按界面类型名、各组内按名称升序，降序反转整个比较顺序，同类型同名称保留原顺序。悬停标签允许自动切换；离开、换目标或身份变化取消旧停留，不冻结精确毫秒数 |
| D13 | 文件批次部分完成后的失败或取消 | 保留已成功项，停止尚未开始项并报告未完成项，不自动回滚；已经提交给系统的操作须如实区分，不承诺撤回正在执行的 I/O |
| D14 | 异步目标和插入锚点变化 | 目标删除、换类型或改变映射路径，取消未提交项并保留来源，不得改投替代对象；仅锚点消失且原目标未变时，追加到原目标末尾 |
| D15 | 回收站等系统对象遇到映射文件夹 | 不支持的对象和目标组合在悬停接收时就拒绝，不显示可执行落点或动作，不等待文件操作报错。右键菜单和实际释放须遵守同一能力判断；混选仍按 D01 处理支持成员，保留不支持成员 |

本模型登记 **105 个情境字段**：来源和目标各 25 个端点字段，共 50 个；选择 6 个、关系 4 个、手势 3 个、命中 9 个、策略 16 个、传输 5 个、环境 7 个、完成条件 5 个，共 55 个。字段含条件适用项和序列输入，105 不是无约束笛卡尔积的维数。

一条完整场景采用以下结构：

```text
场景 = 来源端点 + 目标端点 + 选择结构 + 对象关系 + 手势与菜单
     + 命中位置 + 策略 + 传输方式 + 环境 + 完成条件 + 事件序列
预期 = 接收判断 + 可见反馈 + 操作语义 + 文件变化 + 逻辑归属变化
     + 落点与顺序 + 持久化结果 + 生命周期结果
```

预期来源的优先级为：用户明确需求；仍有实际绑定的菜单、提示和指南；公开 API 或平台协议；对象语义和数据不变量的推导。当前执行代码记录为实现观察，用于比较和定位。

| 依据标记 | 含义 | 对预期的用途 |
| --- | --- | --- |
| 文 | 有实际绑定的产品文案或公开文档 | 确定其明确承诺的行为和适用条件 |
| 协 | Windows OLE 等外部协议 | 确定边界协商、反馈及生命周期要求 |
| 推 | 从操作名称、对象性质和数据不变量推导 | 写明推导条件；不补写算法细节 |
| 观 | 当前代码存在的做法 | 与独立预期比较；不单独成为正确答案 |
| 待 | 文案缺失、相互冲突或只观察到实现 | 保留待确定项；不默认拒绝或通过 |

语言键须核对实际引用和绑定条件。仅存在于语言文件中的旧文案不构成当前产品承诺。相关引用检查规则见第 10 节。

## 2. 情境字段与取值域

### 2.1 来源与目标端点：每端 25 个字段

以下 `E01` 至 `E25` 分别登记为 `source.E##` 与 `target.E##`，共 50 个字段。端点描述容器和入口；实际拖动组件、标签还是文件由 `P01` 决定。

| 字段 | 参数 | 候选取值与边界 | 适用与约束 |
| --- | --- | --- | --- |
| E01 | 宿主位置 | 自由桌面、桌面 Dock、悬浮 Dock、组件/文件夹弹出面、外部 Explorer、其他外部程序 | 弹出面还须记录所属入口和逻辑容器身份 |
| E02 | 容器类型 | 无容器、集合、桌面文件、文件夹映射、集合组、文件组、Lua 逻辑槽位、Lua 文件接收区、其他 Lua 组件、引导组件、Shell 文件夹、Shell 处理对象 | Lua 逻辑槽位和文件接收区是两种不同契约；其他 Lua 组件不能默认当成接收面 |
| E03 | 所属入口形态 | 组件本体、桌面单图标、Dock 入口、组标签、无组件入口 | 位置和形态分别记录；打开 Dock 入口的内容面仍保留该入口身份 |
| E04 | 入口角色 | 普通入口、Dock 独占入口、Dock 映射、常用生成项、运行生成项、固定控制项、不适用 | Dock 映射与独占入口的拖出结果不同；回收站等控制项另有语义 |
| E05 | 弹出面状态 | 未打开、悬停等待、已打开、关闭中、不适用 | 等待时长属于事件序列；打开后不能丢失原始来源身份 |
| E06 | 弹出样式 | 滚动面板、扇形、不适用 | 样式不改变文件归属；是否提供相同拖放能力须分别核对 |
| E07 | 内容视图 | 图标网格、列表、不适用 | 同一内容在不同视图中的语义应相同，命中与插入几何不同 |
| E08 | 活动子项 | 无子项、首/中/末子项、有效但非当前子项、失效子项、不适用 | 组内容投放和组标签投放分别解释；不能将组包装对象当成实际文件目录 |
| E09 | 过滤状态 | 无过滤、分类过滤、搜索命中、跨子项搜索、空结果、不适用 | 必须从可见项目映射到真实对象身份，不能直接使用可见下标作为存储下标 |
| E10 | 数据可用性 | 就绪、加载中、不可访问、对象失效 | 空容器是有容量的合法场景，不等于数据不可用 |
| E11 | 标题栏收起状态 | 展开、收起、不适用 | 收起后的命中区域不同；与弹出面是否打开分别记录 |
| E12 | 悬停自动展开策略 | 开、关、不适用 | 与 E11 联合产生展开序列，不能合并为一个静态形态 |
| E13 | 隐藏桌面时保留 | 开、关、不适用 | 与 V03 联合影响实际可见与可命中状态 |
| E14 | 仅悬停显示策略 | 开、关、不适用 | 来源/目标分别记录；指针离开和菜单打开期间的变化进入 S02/S03 |
| E15 | 隐私模式 | 开、关、不适用 | 内容可见反馈另核对，不能仅由“数据就绪”推导当前内容可见 |
| E16 | 集合外壳样式 | 大文件夹、滚动面板、不适用 | 与内容网格/列表以及弹出面扇形/滚动样式分开；实际改变插入方向和命中几何 |
| E17 | 对象当前占地 | 单格、多列/多行、多格边界、不适用 | 单格是当前组件图标模式的条件；组件或桌面项身份、配置尺寸意图与当前占地分开核对 |
| E18 | 无字紧凑模式 | 开、关、不适用 | 适用集合的图标中心和停留 Handoff 与普通内容插入分别处理 |
| E19 | 所在页面命名 | 有用户名称、无名称、不适用 | 名称影响空页保留；来源与目标分别记录，不能仅保存名称文本就声称已验证清理分支 |
| E20 | 所在页其余内容 | 仅有被移对象、有其他有效桌面项目/独立组件、仅有被收纳或组内记录、加载状态未知、不适用 | 区分移动后变空和仍有内容；隐藏/组内返回位置不能自动当作独立页面内容 |
| E21 | 页面映射角色 | 前置固定显示器页、末屏默认页、附加页、不适用 | 结合 V05/V06 与页面内容判断清理、补齐和编号；角色归类是实现观察，不据此直接补定删除结果 |
| E22 | 桌面项大图标配置 | 无、有且当前生效、有但未经过当前归属规整、不适用 | 配置可独立于当前占地变化；桌面项的大图标与原生组件单图标模式分别建模。入 Dock/逻辑成员后的配置策略见 Q16，未规整输入不冒充正常稳定界面状态 |
| E23 | 所在页列数 | 1、多列、恰可容纳宽度、少于请求宽度、等待期间改变、不适用 | 与行数、对象占地、剩余容量独立；不同页面可有不同网格，不能以显示器尺寸代替 |
| E24 | 所在页行数 | 1、多行、恰可容纳高度、少于请求高度、等待期间改变、不适用 | 与列数分别改变，覆盖 1×N、N×1 和双轴边界；保存/映射后保留各页自身尺寸 |
| E25 | 大图标轮廓 | 圆角矩形、方形、圆形、旗形、菱形、六边形、不适用；方向、正六边形和圆角配置随样本明确 | 网格占地与可见轮廓分开；来源身份不变时，枚举重排不能把另一对象的轮廓或圆角配置套到当前预览 |

入口形态的当前限制来自菜单绑定和 `single_cell_widget_rules.h`：原生五类存储组件在桌面独立单格时可切换组件/图标模式；Dock 仍以自己的入口形态呈现。单图标与列表视图是不同层次，不能合并成一个 `iconMode` 参数。[菜单绑定](../../src/app/widgets/app_widget_context_menu.cpp#L476)、[形态条件](../../src/widgets/single_cell_widget_rules.h#L10)。这些限制是工作区实现观察，新增形态时须扩展取值域。

E11 至 E18 从已有设置文案和交互条件继续拆分，避免用“组件状态”掩盖相互独立的开关。[设置文案](../../lang/zh-CN.json#L923)、[展开与隐藏命中条件](../../src/app/input/app_hit_testing.cpp#L130)、[隐私内容条件](../../src/widgets/widget_base.cpp#L608)、[紧凑集合交互](../../src/widgets/collection.cpp#L1009)。仅改变配色等、不改变交互语义和几何的外观取值可按等价类处理；不能据此省略上述会改变可见反馈或命中的状态。

E19 至 E21 来自仍绑定的页面管理指南以及跨页后清理/映射链。U17 明确保留已命名空页与每屏至少一页；U18 定义固定屏与末屏翻页。具体页角色和后续页面内容会影响保留、补齐与编号。当前 S08 组件、内部文件提交、逻辑成员进入桌面的落点规划、物化文件的新页恢复、选中桌面搜索/缓存及投影已接入实际存储；完整宿主命中、像素预览和布局重建仍未接入。[指南绑定](../../src/platform/usage_guide.h#L142)、[页面保留入口](../../src/app/layout/app_page_grid.cpp#L1531)、[清理及补齐](../../src/app/layout/app_page_grid.cpp#L1752)。

E23/E24 与 H06/H07 补足原模型的独立因素缺口：单项占地或“多屏尺寸不同”不能代表页列/行数，命中格为空也不能代表整页有余量，已有溢出页与仅存在于预览的新页也不同。当前样本覆盖不同页网格、1×N、N×1、部分/完全占用、预留身份替换，以及列/行分别缩小后旧落点失效；等待期间扩大或复杂重排及所有组合仍未全部执行。

### 2.2 选择结构：6 个字段

| 字段 | 参数 | 取值与边界 |
| --- | --- | --- |
| P01 | 操作对象 | 普通文件、目录、已有 `.lnk`、`.url`/应用入口、无真实路径的命名空间对象、组件本体、集合标签、文件来源标签、虚拟文件、图片、文本、URL |
| P02 | 选择数量 | 0、悬停时数量未知、1、2、多项、目标剩余容量、超过剩余容量；未知数量与确认空载荷分别记录；Lua 逻辑槽位另有单项限制，Lua 文件接收区另有 128 项上限 |
| P03 | 选择组成 | 同类、文件与目录、普通文件与快捷方式、不同组件类型、组件与文件、含不支持成员、含重复成员 |
| P04 | 成员来源分布 | 同一容器、同组不同子容器、不同逻辑来源、不同物理目录；界面能否形成该选择另记约束 |
| P05 | 成员顺序 | 当前可见顺序、显式捕获顺序、与文件名排序不同的顺序；投放期间来源重排另建序列 |
| P06 | 文件/入口分类 | 普通文档、图片/媒体、程序、应用快捷方式、目录快捷方式、非程序文件快捷方式、未完成分类的入口、规则中特殊扩展名；与“已有 `.lnk`”这一文件形态分别记录 |

### 2.3 对象关系：4 个字段

| 字段 | 参数 | 取值与边界 |
| --- | --- | --- |
| R01 | 逻辑实例关系 | 同实例、同类型不同实例、跨类型、同组不同子项、跨组、对象自身 |
| R02 | 实际路径关系 | 同一目录、不同目录、源目录自身、源目录的子目录、快捷方式解析后指向自身、路径不可用、不适用 |
| R03 | 存储关系 | 同卷、跨卷、网络位置、不适用；显式移动/复制的语义不由调度方式改变 |
| R04 | 身份与名称冲突 | 无冲突、同身份重复、同名不同文件、大小写别名、目标已存在、队列中预留同名、并发创建同名 |

### 2.4 手势与菜单：3 个字段

| 字段 | 参数 | 取值与边界 |

## 10. 本地化引用检查

用户要求：**确认无用的语言键存在时，默认测试失败。**

改造前的检查主要收集直接字符串调用，全局未引用项默认告警，`--strict-unused` 才失败。当前 [全局绑定收集](../../tests/localization_contract_tests.cpp#L591)、[默认无用键检查](../../tests/localization_contract_tests.cpp#L975) 和 [默认门禁自测](../../tests/localization_contract_tests.cpp#L1393) 已替换该行为：全局与组件无用键在默认调用中都失败。真实有限动态引用和静态分析边界详见 `../localization/README.md`，不能把旧扫描器的限制或原参数语义当作当前结果。

表驱动、条件表达式及返回键的 helper 会产生间接引用。例如 [Dock 提示键选择](../../src/drag_drop/drag_hint_rules.h#L6) 由 [Dock 提示入口](../../src/core/dock.cpp#L3011) 交给 `_LW`，不是该位置的直接字符串调用。某个键另有直接引用不消除这种解析边界。

| 编号 | 改造要求 | 确定失败信号 |
| --- | --- | --- |
| L01 | 全局键、内置组件键及官方组件键分别计算定义与真实引用；默认禁止确认的无用键 | 任一无用键使默认测试非零退出；不能只打印计数告警 |
| L02 | 识别直接、表驱动、条件选择、受约束拼接和声明式数据引用，记录引用位置与到本地化入口的关系 | 有效的间接引用不误报无用；未知解析形态报告覆盖缺口并阻止完整引用审计通过 |
| L03 | 动态引用采用可检查的生产声明/有限取值域，核对声明与实际消费位置 | 声明不存在的取值、缺翻译、过宽前缀、仅为压制失败的无消费者声明均失败 |
| L04 | 未引用报告逐键列语言文件、位置、文本和引用分类；语言键集合、占位符等现有要求继续保留 | 定位到具体键；不能只输出总数 |
| L05 | 语言键删除/新增与相关生产改动同步；确认无用的键从全部语言删除 | 遗留任一语言中的废键失败；不采用历史无用键基线或整批豁免 |
| L06 | 引用存在与界面可达性分开核对；用于行为预期的文案还要核对条件 | 注释、测试代码、孤立常量或永远没有消费者的数据不能单独证明键有效 |
| L07 | 建立引用检查本身的正反样本 | 添加无引用键必须失败；有效表驱动/拼接引用应通过；去掉真实消费者后必须失败 |

新增未识别的动态形态须报告审计边界，不能因检查器无法解析就整批保留。引用规则与门禁见 [本地化说明](../localization/README.md)。
