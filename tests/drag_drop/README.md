# SnowDesktop 核心拖放行为矩阵

本文件维护已确定的产品行为及长期执行集合。预期先由用户操作、稳定契约和数据不变量确定，再选择生产入口。历史 Bug、代码和旧测试可提供场景；旧断言或 helper 组合不是正确性依据。对明确的新实现替代且没有 Bug 证据的差异，按当前产品行为更新预期；不把旧实现的预期继续当成缺陷。

## 已确定的产品行为

| 决策 | 适用情境 | 独立预期与验收边界 |
| --- | --- | --- |
| D01 | 混选组件和文件，所选操作不能处理其中一部分对象 | “处理能处理项目即可”：执行支持的成员，不能因不支持成员而整组拒绝；不支持成员的身份、位置、配置、归属和底层文件保持原状。测试从完整捕获选择开始，逐项对应实际结果，不预先过滤输入或宣称整组成功。组件在 Ctrl/Alt 混选中的边界由 D03 明确；部分处理的反馈文案仍属 Q02 |
| D02 | 容器已按名称、大小或日期等字段自动排序，用户执行有效的手动成员拖动 | “切为手动排序，保留拖后顺序”：成功重排后退出自动排序，按插入语义保留移动成员及其他成员的顺序，刷新、重建与保存重载后保持；拒绝、取消和无有效成员的拖动不得切换排序或改数据。日期表头等禁止手动操作的既有前提仍适用，不由该决定补定 Q07 的比较和分组细节 |
| D03 | 混选普通文件和单图标组件，按 Ctrl 复制或 Alt 创建快捷方式 | “只处理普通文件，组件保持原样”：对所选普通文件执行对应物理复制或创建可解析的快捷方式，原文件保留；所选组件及其子项、成员、位置、配置和原文件不变。没有所选普通文件时不产生文件或目标成员。来源捕获必须保留完整混选，不预先删除组件后绕过过滤链；两类动词分别验收源、实际输出身份、目标归属、可访问位置及刷新/重载。此决定不授予复制组件或创建组件快捷方式的能力 |
| D04 | 外部真实文件同时允许 Move/Copy，无修饰键，拖入桌面或普通原生存储组件 | “同卷默认移动，跨卷默认复制”；多选包含同卷与跨卷来源时“整批复制，保留全部来源”。集合、桌面文件及其组的物理目标为受管桌面目录，映射及其组为原映射目录；判断实际物理卷，不能以组件类型或盘符字符串代替。所有来源与目标同卷才默认移动，其他已明确跨卷批次整批复制。Ctrl/Shift/Alt、Ctrl+Shift 与右键选定动词不受默认规则覆盖；尚未获得路径的异步来源不得在悬停阶段强制渲染，最终动作须在路径可用后兑现。卷身份不可判定的处置仍待用户确认 |
| D05 | Shift 合并同类集合或桌面文件组件 | 目标设置保持不变，去重合并成员后移除来源组件。物理文件、未参与对象及目标稳定身份保持；同身份重复成员只归入一次，完整保存和重载后仍成立。具体合并成员顺序未由此补定 |
| D06 | 成员移出后的组生命周期 | 拖动建成的组剩一个成员自动解组、空组移除；手动创建的组剩一个或为空均保留。转移中的调用栈和拖动上下文存活时不能使对象悬空；原子成员及其内容、设置和文件保留，外层收尾后身份和可访问性正确并持久保存 |
| D07 | 文件直接放到未激活的组标签 | 按命中的标签接收并激活；无插入标记时追加到该子来源末尾，不得用标签序号作为成员插入索引。文件、目标子来源、原有顺序、活动标签及重载分别核对 |
| D08 | 图片、文本、虚拟文件及多格式 URL 内容 | 图片保存为可解码 PNG，文本为 UTF-8，虚拟文件按完整描述批次接收；多格式优先完整文件、图片、URL、文本，虚拟批次缺项时不得退到预览图。网页 URL 建网站快捷方式，直接文件 URL 下载；仅复制并保留来源 |
| D09 | 已有快捷方式再建快捷方式、文件夹快捷方式接收 | 解析到最终目标；文件夹快捷方式按实际目录接收。不得建立指向待清理临时数据的链接 |
| D10 | Dock 跨分区混选与未匹配运行项 | 按对象类型放入对应分区，各分区保持捕获顺序；普通运行图标只有匹配桌面入口才允许固定或映射。资源管理器例外：拖到固定区可创建指向资源管理器本身的入口；拖到文件区仅在识别到当前真实文件夹时固定该目录，优先复用已固定的同目录入口，或唯一桌面入口，否则创建文件夹快捷方式；多个同目录桌面快捷方式仍可固定且不任意移动其中一个。当前目录无法识别时拒绝。新建入口独占 Dock；复用入口保留普通固定/Ctrl 映射规则 |
| D11 | 大图标进入 Dock 或逻辑容器 | 保留大图标配置，容器内按普通跨度显示，返回桌面时恢复原配置；保存、刷新和重载不能丢失配置 |
| D12 | 搜索插入、日期表头、类型排序及标签悬停 | 插入标记对应真实成员，隐藏成员保留相对顺序；有效拖动切手动并在清除搜索后保持完整顺序，无标记追加末尾。日期表头开启时自身成员重排拒绝，搜索不例外。文件组搜索保留来源标题与分组，保持来源顺序，在各来源内部应用类型排序（2026-10-31 用户确认）。来源内部的类型排序规则为：升序为“此电脑、回收站等系统项 → 文件夹 → 文件夹快捷方式 → 其他类型”；其他类型按界面类型名、各组内按名称升序，降序反转整个比较顺序，同类型同名称保留原顺序。悬停标签允许自动切换；离开、换目标或身份变化取消旧停留，不冻结精确毫秒数 |
| D13 | 文件批次部分完成后的失败或取消 | 保留已成功项，停止尚未开始项并报告未完成项，不自动回滚；已经提交给系统的操作须如实区分，不承诺撤回正在执行的 I/O |
| D14 | 异步目标和插入锚点变化 | 目标删除、换类型或改变映射路径，取消未提交项并保留来源，不得改投替代对象；仅锚点消失且原目标未变时，追加到原目标末尾 |
| D15 | 回收站等系统对象遇到映射文件夹 | 不支持的对象和目标组合在悬停接收时就拒绝，不显示可执行落点或动作，不等待文件操作报错。右键菜单和实际释放须遵守同一能力判断；混选仍按 D01 处理支持成员，保留不支持成员 |
| D16 | 组件递归搜索结果 | 来源是临时文件投影，没有持久成员索引；拖入桌面、映射或集合执行真实文件操作。拖到原映射仍按文件路径处理，不误作成员排序。选中与展开仅影响可见范围；刷新或拖拽结束保留搜索及各组展开量 |

D01–D16 保留其已确认的事实范围。表内未补定的行为继续待定义，不推导成默认接受、默认拒绝或通过。当前实现与其中某项不一致时保留失败证据；此测试重构不授权改变产品行为。

## 有界场景与等价类

每条场景记录来源、目标、载荷、手势、能力、关系、序列和可观察结果；只使用改变本条行为的因素。无容器的外部文件来源与具有逻辑所有权的原生成员分开建模。

| 场景族 | 代表输入及风险依据 | 独立预期和生产执行边界 |
| --- | --- | --- |
| 外部文件动词 | 单文件同步 Copy；延迟 Move/Copy/Link；文件加目录批次；释放时改变修饰键 | OLE Enter/Drop → 宿主路由 → 真实 Shell 文件操作 → 实际消息完成 → 刷新与磁盘重载；Copy 保留来源，Move 移除来源，Link 解析真实目标，落到请求格且不覆盖无关文件 |
| 默认动作 | 已确定同卷的延迟真实文件，无修饰键，来源提供 Move/Copy | 悬停不强制读取；Drop 只表示已接受延迟任务，路径获得后兑现同卷 Move；不能用早期占位反馈替代最终文件结果 |
| 拒绝与取消 | Copy 请求遇到仅 Move 来源；OLE Leave；右拖菜单 Cancel | 不启动内容租约，不产生文件、成员或持久化变化；未选中的动作不能执行 |
| 容器接收 | 集合、桌面文件、映射、集合组、文件组中的桌面文件或映射六种所有权/持久化模型，展开形态、延迟单文件 Copy | 相同载荷和动词用于区分六条生产归属路由，不再乘以全部手势/数量/外观。文件进入对应真实目录，归入捕获的成员源一次；根设置、活动子源和非目标成员保持；运行时槽位、保存与重载可访问 |
| 内部成员移出 | 集合、桌面文件各一个选中成员移到空桌面格，另一个成员不选 | 真实来源捕获、目标解析和 `OnLeftButtonUpAt` 收尾；仅改变选中成员逻辑归属，物理字节保留，未选成员仍归原容器；落点与磁盘重载一致 |
| 手动重排 | 已按名称升序的集合 A/B/C，将 B 放到 A 前 | 真实成员选择、命中、释放和保存；结果为 B/A/C，退出自动排序且重载保持，文件字节不变。名称排序是输入准备的独立可观察前提，不从当前比较器生成正确答案 |
| 右拖决策 | 对同一延迟文件选择 Copy 或 Cancel | 执行真实宿主动作菜单，只替换菜单显示边界；按实际文字找到动作返回其当前命令，不检查私有命令数值。菜单出现前无 I/O，选择后最多提交一次 |
| 异步交错 | 同名 A/B 请求，先保留 A 的真实源读取完成消息，再完成 B；A 随后成功或真实源丢失失败 | 保留生产读取、队列、文件提交与 UI 完成。每个任务独立租约、内容和落点；A 的晚完成/失败不能覆盖、移动或结束 B；中间刷新和最终重载保持结果 |
| 异步目标改变 | 延迟文件已捕获集合身份或映射目录，读取完成前用户替换目标身份或更改映射路径 | 在真实源读取和物理提交之间控制交错；取消未提交任务并保留源，不投递到替代对象/新路径；用户修改的目标状态经重载保留 |

集合、文件组件和映射使用相同接收能力时，动词的源保留语义由外部文件动词族覆盖；容器族补充目标目录、所有权、组子源与持久化风险。组与普通容器不是无条件等价，故单独保留组路由。当前执行集合不扩成所有因素的笛卡尔积。

## 执行集合

驱动为 `tests/behavior/core_interactions_tests.cpp`；生产宿主图与测试共用相同实现。`container_access.inc` 只提供场景设置、观察和生产入口调用，`container_scenarios.h` 保存业务断言。外部 Shell provider、菜单显示和完成消息的先后是可控边界，路由、队列、文件提交、刷新和存储不由替身直接返回成功。

| 行为参数 | 对应范围 |
| --- | --- |
| `sync-copy/copy/move/default-move/link/batch` | 外部文件动作、租约、实际 I/O、落点与重载 |
| `unsupported/cancel` | 能力拒绝与 OLE 取消 |
| `interleaved/failed-first` | 反序完成、同名内容、独立失败和刷新 |
| `container-collection/container-files/container-mapping` | 三种原生存储容器 |
| `container-collection-group/container-file-group/container-mapping-group` | 组的捕获子源与归属 |
| `member-collection/member-files/member-reorder` | 原生成员移出和重排 |
| `right-copy/right-cancel` | 实际右拖菜单决策 |
| `target-replaced/target-remapped` | 晚完成期间的目标身份/路径变化 |
| `group-type-contract` | 来源分组内类型排序、异步刷新与磁盘重载 |

测试名称及标签由根 CMake 声明。注册不表示已执行；每次真实命令、首次失败、源/程序身份、耗时和结论在对应提交与批次日志记录。一次性验证程序和故障负向对照留在忽略的任务目录。

## 保留的缺口与待定义项

以下项目仍需按具体风险逐项接入或补证，不能由本表中的邻近场景代称通过：

- D01/D03 的完整组件与文件混选，以及 D05/D06 的合并、建组、组解散生命周期。
- D07 的未激活标签直接接收、D12 的日期表头拒绝、搜索隐藏成员插入及悬停取消序列。
- D08/D09 的多格式内容优先级、图片真实解码、UTF-8 文本、虚拟批次缺项及快捷方式层级；纯物化或解析 helper 仅证明局部边界。
- D10/D11 的 Dock 分区、未匹配运行窗口固定、大图标返回及多屏/DPI；窗口 Pin 模块测试不等同于这些宿主拖动场景。
- D13 的已经提交到系统的部分 I/O 取消边界；当前“先成功 B，后失败 A”只证明独立任务隔离。
- D14 的锚点消失追加、类型改变与真实对象销毁；当前目标身份/映射变化只覆盖未提交任务取消。
- D15 的系统对象能力拒绝、D16 的递归搜索投影拖放；文件组按类型排序已按用户决定覆盖来源分组内排序；旧跨来源全局排序失败保留历史证据，归为已退役预期。
- 明确跨卷与混合卷默认动作、卷身份不可判定策略；已确定同卷不代表其他卷关系。
- 弹出面、图标状态、容量不足、重名策略、自动收纳、锁定/权限变化和所有外部应用兼容性，按实际契约和风险选择；未明确行为不从代码补定。

桌面像素、提示文字、菜单绘制和真实硬件手势由用户实机或稳定等价证据验收。窗口无界面场景可以证明其实际执行的路由与数据结果，不自动证明桌面视觉和 Windows Shell 全部兼容性。

## 独立模块与工具覆盖

这些边界具有核心拖放场景无法代替的持续价值，保留现有设施与可用驱动；入库依据是稳定契约和可观察错误，不是既有测试数量。

| 执行集合 | 独立风险、执行边界与隔离理由 |
| --- | --- |
| `settings/settings-host/recovery` | 真实 JSON 草稿/提交与宿主日志副作用、损坏代际恢复、清空后不复活旧布局；同一隔离宿主驱动，无新公共夹具框架 |
| `search/group-type-contract` | 实际快捷导航结果模型、Everything 边界之外的真实异步合并、文件组来源分组内类型排序与重载；SDK 本身的可用性另验 |
| `widget/lua_runtime` | 实际 Lua API、权限和任务撤权；独立 Lua 进程保护执行/内存预算及错误后恢复，不冻结 hook 或栈实现 |
| `widget_storage_transaction/widget_secret_store` | 跨实例隔离、原子持久化、已发布密文兼容；独立存储进程避免宿主场景掩盖数据边界 |
| `widget_filesystem_handle_store/lua_file_delivery_contract` | opaque 句柄所有权、权限保存撤销、真实 Lua 文件回调失败后的 grant 撤回；不代称宿主命中路由 |
| `widget_author_test_runner/widget_author_tools/widget_package_file_export` | 产品作者工具的实际 Lua 执行、包审查/安装/导出与原文件保持；运行隔离的作者输入，不读用户组件 |
| `dock/hook_stable_entry` 及跨位数条目 | Pin 所有者销毁只撤销自有窗口状态；另保留真实 owned 进程的 Hook 映像代际及跨位数部署，不能以 Pin helper 代替 |
| `application_control` | 真实命名管道客户端、服务端与协议生命周期；不代称所有宿主控制动作验收 |
| `http_security/http_network_integration` | URL/域/来源安全边界及 owned loopback 传输取消、重试和缓存；不使用真实远端 |
| `localization_contract` | 实际语言、组件资源、消费引用与参数契约；不代称视觉排版或全部 UI 可达性 |
| `manifest` 与工具 packaging/deployment 条目 | 同一构建实际清单文件/片段/许可证 SHA，以及生产打包入口的损坏拒绝和路径隔离；不推送、发布或登录 Steam |
| `tools` | 复用既有 CMake/CTest 及选择、执行权、等待、记录等真实工具流程；应用结果与工具结果分别报告，临时探测不扩成常规测试 |

旧原生驱动、实现写法护栏、重复规则组合和一次性探测随旧体系退役；有独立价值的上述模块驱动重新按契约准入，保留真实隔离需求。测试数与源码行数不表示产品覆盖程度。精确退役路径、原失败和候选身份留在对应提交及忽略的任务证据中。
