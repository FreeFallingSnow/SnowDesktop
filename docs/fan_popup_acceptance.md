# 可滚动扇形弹窗：实现与待验证场景

## 入口与保存

- Dock 的文件夹栈、文件夹映射和集合，以及桌面集合的右键菜单提供“展开方式 → 默认 / 扇形（可滚动）”。选择只影响当前对象的弹窗。
- 集合原有的内联布局和列表详细信息配置继续保留；恢复“默认”后按原配置显示。
- 桌面文件夹映射仍使用原来的内联视图；进入 Dock 后才显示扇形展开选项。
- `DesktopWidget` 与 `DockEntry` 的布局 JSON 新增可选布尔字段 `fanPopup`。缺省为 `false`，错误类型拒绝载入。旧宿主忽略该字段后重新保存，可能丢失此偏好。Lua 公共 API、组件清单版本和 capability 不变。

## 呈现与交互

- 扇形最多按七行计算首屏高度，并限制在当前工作区内；项目没有数量截断，“查看全部”不是继续浏览的必要步骤。
- 滚动使用像素偏移，行的横向偏移由当前可见纵向位置计算。图标、文字、点击、重命名和拖放使用同一行几何。
- 扇形的拖放插入线按纵向排列显示横线；保留剪切状态与快捷方式箭头。上下 Dock 的扇形根部图标优先对齐来源入口，侧边 Dock 的动画使用实际锚点。
- 扇形采用分离的圆角项目背景，保留标题、文件夹排序按钮和滚动条。浅深色沿用集合弹窗配色；不在整个透明区域叠加矩形玻璃背景。
- 展开和收回按距起点的距离错开进度；复用宿主动画调度与速度设置。关闭动画时立即呈现，选择淡入淡出时不做空间移动。
- 扇形渲染只遍历当前可见行。目录枚举、图标加载、选择和文件操作沿用原有弹窗流程。

## 自动化覆盖

- `scripts/test.bat name dock_and_window_rules`：不同缩放、弧线方向、部分滚动后的命中区域、最后一项可达性、空集合和动画端点。
- `scripts/test.bat name application_data_lifecycle`：按对象隔离偏好、旧布局缺省值、保留列表配置、文件保存重载和非法字段拒绝。
- `scripts/test.bat name localization_contract`：全部十种语言的文案键与契约。
- `scripts/test.bat name popup_animation_rules`：原有弹窗动画生命周期与反向切换规则。

## 待用户实机验证

此文档不表示下列场景已经通过。桌面宿主不使用桌面自动化操作。

1. 分别在 Dock 文件夹栈、Dock 文件夹映射、Dock 集合和桌面集合上开启扇形；另一个对象仍保持默认，重启后偏好保留。
2. 用空集合、单个项目、七个项目及数十个项目检查展开、滚动至最后一项、收回和快速反向开关。
3. 检查长中文和外文文件名、浅深色、不同缩放、多显示器、四边 Dock 与靠近屏幕边缘的位置。
4. 滚动后点击打开、右键、重命名、多选、框选、拖出、拖入和排序，确认操作目标与画面一致。
5. 切换宿主动画为关闭、淡入淡出及缩放，检查减少动态效果策略和速度设置。
6. 恢复默认展开，核对网格、列表及详细信息配置和全部原始文件保持完整。

本轮为交付实机验证的尝试；定向测试不能证明桌面视觉和交互已验收。用户确认目标场景后，再运行完整测试并创建验证提交。
