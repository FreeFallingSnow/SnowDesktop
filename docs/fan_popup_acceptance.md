# 扇形弹出层实机验收

## 参照与范围

本轮依据 macOS Dock Stacks 的经典 Fan 视图调整外观与展开方向，按用户要求增加沿扇形滚动。参考 [Apple 使用手册](https://support.apple.com/zh-cn/guide/mac-help/mchl231f08fb/mac)、[AppleInsider 原生截图](https://photos5.appleinsider.com/gallery/24991-33271-stacksbasics00005-xl.jpg) 和 [MacMost 实机视频 4:26](https://www.youtube.com/watch?v=lK0FSpKR-6Q&t=266s)。没有测得 Apple 的精确动画参数，角度、间距和缓动属于本项目的近似实现。

- 图标与短文件名标签一起倾斜、沿弧线排列。图标使用真实轮廓的柔和下投影，保持周围透明。只给文件名加半透明小底色，不绘制包围整个扇形的面板、标题栏、排序按钮或滚动条。
- 根据可用高度限定弧线窗口，滚轮推动项目沿曲线移动，位置和倾角连续变化，两端淡入淡出。支持小于一个滚轮刻度的输入；不整组平移、不显示滚动条。末端“查看全部”保持固定。沿扇形滚动是用户要求的产品扩展，不声称 macOS 原生提供相同行为。
- macOS 的末端操作通常打开 Finder；本项目使用“查看全部”打开现有网格，在其中滚动访问全部内容。这是有意的产品适配。
- 顶部 Dock 向下展开；靠左时镜像标签与弧线。侧边 Dock、空间不足及空内容使用现有网格。这些回退不改写对象保存的偏好。
- 打开时图标保持正常尺寸，从源位置逐个上升或下降，并向侧方弯曲、旋转展开；不做图标或整组缩放。关闭反向合拢，淡入淡出和关闭动画设置仍生效。
- 关闭后再次打开恢复扇形并回到首项；重命名时临时切到网格，使用原有编辑器。
- 拖放插入线沿目标项目倾斜；最近插入位置和前后判断使用同一旋转几何。滚动期间同步刷新拖放目标。
- 图标模式从扇形拖出时，虚影截取图标本身并把图标中心与桌面落点对齐到指针。绿色目标框只包围图标，绘制和命中共用同一倾斜区域。

## 入口与保存

- Dock 文件夹栈、文件夹映射和集合，以及桌面集合，通过各自右键菜单的一级“扇形展开”直接切换，显示 Fluent 图标及开关状态，不创建展开方式子菜单。
- 保留原有网格、列表和详细信息配置。关闭“扇形展开”后按原配置显示。
- 本轮没有修改已存在的 `fanPopup` 存储字段，也没有修改公共 Lua API、组件清单或 capability。
- 文件枚举、图标加载和文件操作继续复用现有流程；扇形只绘制其可见项目。

## 自动检查

- `scripts/test.bat name dock_and_window_rules`：不同缩放、上下方向、镜像、负坐标下的旋转边界和点击命中；首末项目可达、小滚轮增量和动画中反向输入；倾斜插入线、绿色框与命中一致；非直线展开轨迹。
- `scripts/test.bat name menu_icon_render`：扇形开关使用的 Fluent 图标在不同 DPI 下可见。
- `scripts/test.bat name ui_animation_scheduler`：现有调度与取消约束。
- `scripts/test.bat name slot_runtime_contract`：复用的拖拽指针锚定、虚影快照和目标生命周期约束。
- `scripts/test.bat name application_data_lifecycle`：现有扇形偏好读写、旧布局缺省值、非法值拒绝。
- `scripts/test.bat name localization_contract`：全部十种语言的文案键契约；另行人工检查翻译。
- `scripts/test.bat name popup_animation_rules`：弹出层动画生命周期及反向切换。
- `scripts/test.bat name desktop_keyboard_rules`、`scripts/test.bat name right_click_contract`：既有键盘及右键约束。

## 待用户实机验证

本清单不代表以下场景已经通过。桌面宿主不使用桌面自动化验证。

1. 在 Dock 文件夹栈、Dock 文件夹映射、Dock 集合和桌面集合开启扇形；其他对象保持默认，重启后确认偏好保存。
2. 使用一个项目、七个项目、数十个项目及空集合，确认扇形透明、文件名紧凑、没有大背景，项目保持正常尺寸，从源位置沿曲线展开并收回；观察是否仍有缩放感。检查图标阴影在浅色、深色和复杂壁纸上的可读性。快速反向开关和禁用动画都正常。
3. 在扇形内用普通滚轮与高精度触控板连续及反向滚动，确认项目沿弧线移动、两端淡出、能到达最后一项，末端“查看全部”保持固定。点击它可切换网格。关闭再开仍使用扇形，回到首项。
4. 检查长中文、英文文件名，浅深色、不同缩放、多显示器、靠边位置、顶部和侧边 Dock，确认图标和文件名未被裁切。
5. 单击选择、双击打开、右键、框选、多选、拖出和拖入：旋转后的图标及文件名可命中，透明间隙不会误选项目；上下方向的倾斜插入线与结果一致；滚动时拖放指示不滞留在旧位置。尤其检查图标模式从图标或标签起拖，虚影和实际落点应跟随指针；绿色目标框应倾斜贴合图标，透明外接矩形角落不应触发绿色命中。
6. 扇形内用方向键选择，Home 到第一项、End 到“查看全部”、Tab / Shift+Tab 循环切换，Enter 打开当前项或网格。重命名应先转入网格，编辑框位置正确。
7. 关闭一级菜单“扇形展开”后确认列表、详细信息、排序与原始文件内容保持不变。

构建和自动测试只能提供程序与几何规则的证据，不能代替用户原始场景的视觉验收。本轮按 `try` 交付；用户确认后再运行完整测试并记录 `verify`。
