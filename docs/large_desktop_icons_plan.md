# 大图标实现与验收说明

本轮代码位于 `release/v1.0.5.0`，日期为 2026-09-08。实现以 `try` 提交保存，尚未发布；编译与自动化测试不代表桌面实机验收通过。

## 使用入口和默认行为

单选普通桌面项目，右键选择“转为大图标”。有效解锁时尝试原位置 2×2；空间不足进入占位预览，鼠标选择落点，方向键调整占格，点击或 Enter 确认，Esc 或右键取消。两种路径转换成功后均留在桌面，不自动打开设置。未解锁打开现有高级功能入口。

大图标右键保留原项目适用命令，新增“大图标设置”和“还原为普通图标”；三项大图标菜单命令均有图标。悬停时右下角显示与无标题组件同尺寸的圆角点手柄，保留组件的手柄命中范围；宽高独立吸附网格，冲突落点不能提交。最小 1×1，最大受页面约束；外框和间距复用组件几何，不扣普通标题行。

大图标支持中键拖动，超过现有移动阈值后进入桌面拖放流程；中键单击只选择，不打开项目。拖入浮动容器、进入 OLE 及返回桌面时，均按发起拖动的中键状态决定继续或结束。

原始图标默认始终居中，目标尺寸为短边的 60%，低清图不强行放大，使用独立素材缓存绕过普通图标美化链。默认悬停或键盘聚焦时显示浮动标题，标题不接收鼠标事件。整个矩形外框均可选择、打开、右键和拖动，包括透明区域和圆角边缘。单击、双击沿用已有设置；选中状态使用独立描边，不再绘制左上角圆点。

背景默认自动取色，首次加载立即使用主题中性色，常态 65%、悬停 80%。取色混合强度与不透明度分别设置，自动与手动颜色分别保留，可主动设为透明。圆角、边框创建时参考组件参数，此后独立保存。阴影默认关闭。

详细设置使用现有 WinUI 设置进程，按项目定位，分为“内容与尺寸、外框与背景、标题与动效”，提供当前外观预览。设置卡片铺满内容区，复用现有自适应设置行：宽窗口标签与控件左右排列，窄窗口上下排列。名称、来源和预览合入顶部卡片，颜色按钮显示色块和十六进制值。可调整占格、内容比例、图片适配、裁剪焦点、背景、圆角、边框、阴影、标题样式及效果。连续操作先预览，操作结束后提交；离散选项直接提交。滑块和颜色选择等连续预览可用 Esc 撤销。保存失败保留已提交状态，显示错误并提供重试。

“还原为普通图标”清除大图标配置、恢复单格及全局美化，始终允许。“恢复原始图标”只撤掉封面或自选图片，保留其他设置，需要有效解锁。

## 标题和动效

| 设置 | 可选项或初始值 |
| --- | --- |
| 标题 | 默认浮动，可选左移显标题 |
| 悬停内容 | 无、左移显标题、轻微放大、轻微上浮，主位移互斥 |
| 悬停外框 | 无、背景增强、边框高亮、阴影增强；默认背景增强 |
| 按下 | 默认轻微收缩，可关闭 |
| 启动 | 无、一次轻跳、一次脉冲；默认无，仅表示命令已提交 |
| 封面悬停 | 无、轻微放大、标题衬底 |
| 参数 | 延迟 120 ms、进入 200 ms、退出 160 ms；放大基线 1.06，按下基线 0.96 |

左移模式须主动选择：静止居中，悬停保持原尺寸左移，右侧标题最多两行，长文本省略并保留完整名称提示。窄框、竖长框、封面和减少动画时回退浮动标题。快速移入移出从当前进度反向过渡。菜单、拖放和尺寸调整期间隐藏标题、暂停悬停。动效接入宿主动画与帧率调度，过渡结束停止动画刷新。

设置页预览与桌面共享内容几何和有限动效状态，包含阴影、完整悬停过渡、按下及单次启动反馈。预览读取宿主的网格外框、DPI、动画速度与帧率限制，过渡结束移除逐帧回调。WinUI 窗口和桌面的最终交互一致性仍需实机验收。

## 授权、布局与容器

宿主使用现有有效解锁结果检查创建、尺寸及外观修改、编辑设置、图片导入和主动刷新。设置进程仅传递配置值和素材引用，宿主负责保存。解锁失效撤销尚未提交的预览，保留既有配置、正常打开与文件操作、移动、标题、动效及自动素材恢复；重新解锁恢复编辑。完整备份恢复保留存量，普通复制后的新文件不继承大图标资格。

实际迁入 Dock、悬浮 Dock、集合等收纳容器成功后清除该实例的大图标配置。拒收、失败和取消不提交退化；批量接收依成功项目处理。Dock 保留桌面项目时创建普通 Dock 入口，原实例仍为大图标。已退化项目拖回桌面保持普通图标。将文件交给应用打开或向 Lua 组件提供文件引用不算迁入收纳容器。

布局区分期望跨度和临时适配跨度。排序、跨页、跨屏使用完整跨度。显示环境缩小时重新安置并临时适配，恢复后再尝试期望跨度；主动拖到放不下的位置拒绝落点。包含大图标的混合选择在翻页预览中保留源位置，接收成功才提交。

## Steam 与素材服务

识别 `.url` 的 `steam://rungameid/<id>` 与 `steam://run/<id>`，只接受有效 32 位 AppID，不把非 Steam 游戏的长快捷方式 ID 当作商店 ID。

素材优先顺序为自有缓存、Steam 本地 `appcache/librarycache`、允许联网时的 Steam 素材服务。兼容旧版平铺、AppID 目录和哈希子目录。联网通过 `IStoreBrowseService/GetItems` 解析素材元数据及真实文件名，再下载图片，不能只依靠旧版固定图片路径。获取失败保留最近可用封面；从未取得封面时使用原图和默认背景。

本地封面是 Steam 已下载的库图片，不是快捷方式小图标放大。读取缓存无需 Steam 正在运行；联网不要求用户登录或填写密钥。该元数据接口不属于 Steamworks 承诺稳定的公共素材契约；下述真实服务样本已验证，宿主内展示仍需发布前验收。

自动方向按比例降低裁剪损失，手动方向优先；选择器提供实际横竖缩略图和来源。尺寸预览继续用当前素材，提交后才补取所需方向。语言使用当前应用语言，缺失时回退英语。首版不扫描多个账户自定义库图，可通过本地选图导入。

“仅本地”禁止新的元数据和图片请求，已有缓存可以继续显示。手选图片优先于自动来源，迟到结果不能覆盖新选择或让已还原、迁出的实例重新变大。

| 约束 | 当前实现 |
| --- | --- |
| 导入 | PNG、JPEG、BMP、ICO；校验后保留源文件字节并复制到受管目录 |
| 上限 | 单文件 16 MiB，源图 1600 万像素，先检查再解码 |
| 解码 | 后台按显示需要缩小，独立生成供设置页展示的 PNG |
| 并发 | 至多两个素材任务，匹配 AppID、方向、语言等条件的请求合并 |
| 内存 | 解码缓存预算 128 MiB，计入仍被实例持有的素材 |
| 磁盘 | 自动缓存预算 512 MiB，回收未引用素材；手选原图不进入自动回收 |
| 失败 | 短期退避 120 秒，404 记录 24 小时，主动刷新绕过对应失败记录 |
| 回调 | 项目身份、素材变体和请求代次校验，丢弃被取消或替代的结果 |

## 数据兼容与备份

现有桌面项目和布局记录新增可选 `largeIcon` 对象，自身版本 1，布局根版本仍为 1。没有该对象仍是普通图标，不以跨度推断启用状态。配置保存期望跨度、内容与素材引用、裁剪、背景和外框、标题及效果；授权凭据、动画进度、加载状态不保存其中。重命名和 Shell 刷新按原身份保留配置。

素材在应用数据目录 `large-icons/`，配置只接受受管文件名。完整备份包含手选图和当前封面，继续排除授权缓存。第一次写入含大图标的布局前，通过现有完整备份服务在状态根目录 `LargeIconUpgradeBackup/FullBackups/` 保存独立升级前备份；失败则阻止本次写入，不依赖会轮换的 `last-good`。

旧宿主可能忽略并在保存时丢弃新字段。回退旧版使用升级前完整备份；重新升级恢复新版完整备份，不承诺旧版无损编辑新版布局。使用现有应用数据管理流程恢复。

本次新增宿主配置类型、设置定位路由及私有 IPC，不新增 Lua API、清单字段或 capability，不提高组件 `apiVersion`。主要入口：`src/app/app_large_icons.cpp`、`src/app/app_large_icon_interaction.cpp`、`src/large_icon_assets.cpp`、`src/large_icon_config.h`、`src/winui/large_icon_page_presenter.cpp`。
