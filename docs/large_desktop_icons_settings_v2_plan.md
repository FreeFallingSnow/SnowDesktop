# 大图标设置重构规划（第二版，实施中）

依据 2026-09-08 用户确认的设置草稿及标题粗细、颜色补充要求实施。本文替代旧规划中背景、内容、标题和动效的设置组织；具体完成情况以代码与验证记录为准。高级解锁、跨度、容器退化、单格拖动虚影、中键拖动、缩放停绘及组件手柄行为继续沿用。

可交互的页面草稿见 [HTML 设置页草稿](prototypes/large-icon-settings.html)。草稿使用普通图标、Steam 和窄框示例展示条件显示、控件联动及二级导航；仅为层级确认，不执行宿主配置保存、图标识别、Steam 下载或桌面效果渲染。

## 1. 页面结构与默认行为

页面采用组件设置同类的二级页结构，归属于“图标设置”。内容只保留背景、图标、视觉效果三个设置分组；移除常驻预览及占格尺寸。

- 顶部使用设置窗口已有的返回按钮、二级页标题及项目名称。导航关系为“图标设置 → 大图标设置（当前项目）”，在同一设置窗口内切换，不再作为没有父级的独立设置入口。
- 占格尺寸不出现在设置页，也不在折叠项中保留入口；外框尺寸通过桌面上的组件式缩放手柄调整。图标分组的“图标大小”仍保留，只控制内部图片比例。
- 删除设置页常驻预览及其占位空间。位置与裁切直接通过左右、上下两行控制，不另设九宫格或图上拖动编辑器。
- 三组采用同一套设置行，标签在左，编辑控件和逐项恢复按钮在右；连续数值统一使用“滑杆＋数值输入框＋恢复按钮”控件组，窄窗口换行但保持动作靠右。
- 只显示当前模式需要的子项，按从属关系缩进；不将背景、图标、视觉效果再拆成三级导航页面，不增加重复选择器或常驻高级参数列表。
- 每项重置恢复该项默认值；切换模式保留其他模式的已保存配置，不重置图片、裁切或手动位置。
- 普通项目默认：原位置创建 `1×1`，统一纯色默认背景、原始前景图标居中、短边 60%、动态标题；转换不打开设置。已有跨度保持不变。图标背景色填充是识别成功后可选的独立预设。
- Steam 游戏默认：图标填充、读取到的 Steam 背景图、裁切填充、轻微缩放。
- 普通项目切换到“图标填充”时，默认将原始图标等比放大、居中裁切铺满外框；此模式只绘制填充图片，不绘制组件背景或独立前景图标层。
- 大图标外框之外的悬浮标题全部取消。默认悬停不显示名称；名称仅在启用动态标题后于框内出现。保留设置页名称和无障碍名称。

### 1.1 二级页导航与返回

- 从桌面右键直接打开大图标设置，也必须建立“图标设置 → 当前大图标”的父子关系；即使设置进程首次启动、没有历史记录，返回按钮也能到图标设置页。
- 从设置窗口内进入时沿用统一导航机制。返回图标设置页恢复父页原有滚动位置和焦点；重复打开同一实例不重复堆叠相同历史项。
- 左侧导航保留图标设置所属项的选中状态，不新增与其并列的“大图标设置”一级入口。返回按钮与已有键盘返回操作使用同一规则。
- 选择另一实例时更新当前二级页的项目名称和编辑会话，返回目的地仍为图标设置页，不让返回键依次遍历先前编辑过的图标。
- 离开前结束连续调整并提交合法修改；保存失败时明确显示错误和重试入口，不静默丢弃用户操作。已删除、还原或迁入容器的实例退出失效会话，返回图标设置页。
- 复用组件二级页的页面容器、标题、间距和返回行为；不以复制组件的实例业务逻辑代替导航复用。

### 1.2 统一数值控件与位置设置

- 圆角、大小、不透明度、模糊及效果强度、边框和高光宽度、字号、渐变角度及位置等连续数值使用同一控件组。数值框可以直接输入，单位明确；滑杆和数值框双向同步，恢复按钮只恢复当前行。
- 拖动滑杆期间沿用即时展示、结束提交规则；数值输入确认后提交，非法输入不写入配置。不同显示条件不改变已保存值。
- 位置类设置统一拆为“左右位置”和“上下位置”。前景图标的位置与填充图片的裁切位置分别保存、互斥显示，不出现两套同时控制同一图片的入口。
- 图标位置按可移动范围归一化：0% 对应左端或顶端，100% 对应右端或底端，50% 居中；以图标实际尺寸和可用区域计算，不让 0% 或 100% 把图标移出外框。
- 裁切位置按对应方向的裁切余量归一化，默认 50% 居中。没有裁切余量的轴置灰，说明无需调整；完整显示时隐藏两行裁切设置。
- 渐变角度使用单条滑杆及角度数值框，不再使用方向盘；渐变范围分别使用起始位置和终止位置两行控件。
- 非连续选择仍保留合适控件：开关、模式下拉框、颜色选择器和文件选择按钮。动态标题的左移／上移属于效果类型选择，使用下拉框，不转换成任意位置偏移。

## 2. 背景

背景样式平铺：默认、图标背景色填充、图标填充、跟随组件、深色、浅色、毛玻璃深色、毛玻璃浅色、亚克力深色、亚克力浅色、自定义。

| 样式 | 行为与展开内容 |
| --- | --- |
| 默认 | 固定使用默认美化底色 `#E8ECF4`，不透明度 65%；不取色、不展开颜色或材质参数 |
| 图标背景色填充 | 有可靠底色时才出现；以识别色不透明填充。已选中后即使资源暂不可用仍保留选项和状态，临时使用默认底色 |
| 图标填充 | 只有图片层；常用项为来源、换图和缩放。图片详细设置收纳适配、裁切位置与 Steam 选项 |
| 跟随组件 | 实时读取全局组件外观，包括渐变与材质 |
| 各组件预设 | 独立采用所选组件预设，不展开内部参数 |
| 自定义 | 颜色与填充展开；材质、边框与高光默认收起 |

### 2.2 取色、共享引擎与兼容

- 大图标颜色选择器中，识别成功时显示“使用图标背景色”，有主题色时显示“使用图标主题色”。适用于背景、渐变端点与色点、边框、手动标题颜色。点击仅填入当前颜色，不切换背景样式，也不建立持续取色关系。
- 组件颜色选择器不显示图标取色按钮。组件渐变保留起止色、各色透明度、角度、范围、色点与重置能力。
- 大图标图标背景色预设持续使用素材识别结果；原图仅共享底层取色算法，不走图标美化处理链。
- Dock 使用完整组件背景参数，不再禁用 `panelGradient`。任务栏主背景与各动态规则传递相同渐变描述，在现有纯色／毛玻璃／亚克力材质上增加渐变色层，停用后恢复 Explorer 原始显示。
- 大图标新增预设值 `-5`（默认纯色）、`-4`（图标背景色填充）及 `gradientOpacity`；`-3` 保留旧默认模式的读取和显示。编辑旧模式时转为对应预设或自定义参数，不在加载或授权失效时写回。旧默认渐变完整迁移颜色、透明度、角度、范围和色点。
- 布局根版本及大图标配置版本保持；这是预设取值和可选字段扩展。旧构建可能拒绝新增预设值，回退使用升级前完整备份。任务栏私有共享内存协议升级为 v6，宿主与 Hook 同步构建并重载 Explorer。无新增 Lua API、capability 或组件 `apiVersion`。
- 首次写入新预设值前，建立独立的 `LargeIconPresetUpgradeBackup` 完整备份，包含原布局与图片、排除授权缓存；不复用更早的 v1/v2 升级备份，不覆盖已存在的预设升级备份。备份失败时保存失败并保留原布局。

### 2.3 图标填充和 Steam

- 普通项目提供“原始图标 / 本地图片”来源，首次开启默认原始图标；Steam 游戏额外提供“Steam 背景图”，默认使用素材服务读取到的背景图片，不再叠加游戏原图标。
- “图标填充”是独立的纯图片模式；“Steam 背景图”是这个模式内的素材来源，两者不在页面其他位置重复出现。
- 默认等比放大并居中裁切，铺满整个外框。提供独立填充缩放 25–300%，默认 100%，相对于适配结果缩放；缩小后空余区域保持透明，放大后重新计算裁切余量。此处原图作为填充素材使用，不受前景图标 60% 比例或低分辨率图标不放大的规则限制。
- 本地图片：选择、更换、恢复默认来源；沿用静态格式 PNG、JPEG、BMP、ICO 和宿主管理的导入副本。
- 适配提供“裁切填充 / 完整显示”。默认裁切填充；只有实际存在可裁切方向时才启用相应焦点调整。图片自身透明区域及完整显示的留白保持透明，不补组件背景、智能底色或其他底板。
- 裁切采用“左右位置”和“上下位置”两行滑杆＋百分比数值框＋恢复按钮，分别控制横向及纵向裁切焦点；不再提供九宫格、图上拖动或另一套重复偏移入口。默认及恢复值均为 50% 居中。
- 只有来源为 Steam 背景图时才展开实际可用素材的方向、真实缩略图、来源状态、仅本地和主动刷新；选项以实际读取到的素材为准。
- 自动来源继续本地优先、联网补齐，沿用语言回退、失败缓存、限流和陈旧结果隔离。手选图片优先，迟到的 Steam 结果不得替换它。
- 素材失败保留最近可用图；Steam 背景从未成功取得时，暂用原始图标放大裁切作为同一图片层的兜底，背景到达后替换。任何图片都未就绪时显示遵循圆角和整体透明度的临时中性占位，不调用组件材质或独立前景图标层；图片加载后撤去占位，保留图片本身的透明区域。
- 开启后隐藏组件材质相关设置和整个前景图标设置分组，仅保留填充来源、适配、裁切、独立圆角及适用的视觉效果；此前的材质和前景配置保留，退出后恢复。

### 2.4 独立圆角

- 圆角独立于背景模式，在背景分组固定位置显示，所有样式都可调整。
- 沿用 0–100% 表述，100% 对应短边的一半；新建及重置匹配当前组件圆角，之后独立保存。
- 背景填充、图片、描边和动效遮罩共用最终圆角几何。

## 3. 图标

本分组仅控制背景之上的前景图标，不承担背景图片设置。

| 项目 | 规划 |
| --- | --- |
| 图片替换 | 原始图标或本地静态图片；提供更换与恢复原始图标，打开目标和项目名称不变 |
| 大小 | 相对外框短边的比例，默认 60%；保持宽高比；原始低分辨率图标保留不强行放大的规则 |
| 左右位置 | 滑杆＋百分比数值框＋恢复按钮，0–100% 对应可用水平移动范围，默认 50% 居中 |
| 上下位置 | 滑杆＋百分比数值框＋恢复按钮，0–100% 对应可用垂直移动范围，默认 50% 居中 |
| 图片填充背景 | 隐藏整个图标设置分组并停止绘制前景图标层；前景图标及其配置保留，切回其他背景后恢复 |
| 动态标题效果 | 静止位置固定居中；位置控件禁用并说明由效果控制，退出动态标题后恢复已保存的手动位置 |

前景替换与背景填充必须保存为不同素材引用。更换封面不能覆盖前景替换图，切回“默认”也不能把整张封面误当作前景图标。

## 4. 视觉效果

统一为单选：“无效果 / 3D 效果 / 动态标题 / 轻微缩放 / 边缘柔光 / 单次扫光”。不保留旧的悬停位移、外框增强、按下、启动、封面悬停等一长串组合开关。普通选择、焦点和点击语义继续保留。

新建普通图标层默认动态标题，Steam 等图片填充默认轻微缩放。效果恢复按钮按当前背景模式选择默认值，已有布局保存的效果不变。切入填充时，当前动态标题改为轻微缩放；无效果及其他可用效果保持。空间不足仍暂停动态标题，不缩小原图。

### 4.1 无效果

维持当前背景和图标外观，不发生悬停位移、倾斜或标题出现。不展开任何效果参数。

### 4.2 3D 效果

采用草稿中的“随鼠标轻微倾斜的卡片，带光影变化”。该方案随“其他没问题了，开始实施”一并进入实施范围。

- 鼠标进入后根据相对位置产生轻微透视倾斜，移出平滑复位；默认无名称显示。
- 页面只展开“效果强度”，使用滑杆＋数值框＋恢复按钮，不再提供轻微、标准、明显的分段选择；具体强度范围随 3D 效果定义确定。
- 物理占格、鼠标命中框和碰撞规则固定；背景、原生模糊、内容、圆角及边框要在同一几何下呈现。
- 原生毛玻璃/亚克力背景涉及独立合成层，3D 与其几何一致性必须先做技术验证，再确定具体绘制路径。不能只倾斜图标却宣称完成整卡片效果，也不能悄悄把材质改成纯色。
- 3D 内容已接入 Direct2D 整框投影；原生模糊使用相同矩阵与投影区域，实际桌面对齐仍待实机验证。

### 4.3 动态标题

- 方向默认“自动”，同时支持指定“向左移动，右侧显示标题”或“向上移动，下方显示标题”。自动模式优先横框左移、竖框和方框上移，当前方向放不下实际图标和标题时尝试另一方向。
- 静止状态图片居中，无常驻标题；悬停后图片移入左侧/上侧区域，文字在腾出的右侧/下方居中出现。
- 当前大图标的右键菜单打开时直接展开动态标题，移入子菜单后仍保持；菜单关闭后按实际指针位置和键盘焦点恢复悬停状态。只影响当前桌面实例，不使其他选中项展开；图片填充模式仍不支持标题。菜单内切换视觉效果时立即更新此状态。
- 前景图标模式：背景保持不动，前景保持原尺寸移动；空间不足时禁用对应方向，不为塞标题强行缩小原图。
- 图片填充模式不支持动态标题：选项置灰、参数隐藏、停止相关动画。原有动态标题参数保留供切回图标层使用。
- 原始图的完整展示规则与图片填充的裁切规则分开判断可用性。横向和纵向分别计算，不能因为“向左”不适用就禁用“向上”。
- 标题为大字，默认 24 CU；独立字号和粗细使用滑杆＋数值框＋恢复按钮。粗细为 100–900，步长 100，默认 600。最多两行，超长省略，无独立背景胶囊。
- 标题颜色默认自动：跟随组件、固定组件预设和自定义组件材质使用实际解析后的主题前景色；默认背景及图片填充按承载区域选择可读颜色。关闭自动后显示手动颜色选择器，切换自动/手动保留手动颜色。各项可独立重置。
- 超长名称不再弹出完整悬浮提示。需要完整名称时使用设置顶部名称或原有项目属性；保留无障碍名称。
- 进入延迟、进入/退出时长先采用一致默认值，收进内部默认配置；首版页面不单独平铺毫秒参数。
- 快速反向悬停从当前姿态继续，不排队。键盘聚焦可以呈现相同框内标题；减少动画时直接切换静止/展开状态，不出现外部浮动标题。
- 用 DirectWrite 按实际名称、字号、字重测量一至两行标题。图标与标题优先按 12 CU 间距组成居中的紧凑组合；空间紧张时缩短边距与间距。位移只为实际文字腾出空间，图标尺寸保持不变。垂直于移动方向的图标边缘无需额外预留文字边距。
- 动态标题使用原动效时长的 60%：默认延迟 72 ms、进入 120 ms、退出 96 ms；叠加宿主动画速度设置，快速反向从当前进度继续。
- 缩小外框后，手动方向不可用则暂停；自动模式尝试可用方向，两者都不可用时暂停并说明原因；恢复足够尺寸后恢复。静默回退到已删除的悬浮标题不属于本方案。

### 4.4 轻微缩放、边缘柔光和单次扫光

- 三项同时接入右键视觉效果子菜单和详细设置。效果菜单不配图标，仅当前选中项打勾。保持单选，只展开当前效果的参数，每项使用滑杆、数值及恢复按钮；切换效果保留已保存参数，编辑仍由宿主检查解锁。
- 轻微缩放：默认放大 4%，可调 0–10%；以当前图片中心放大，外框、占格及命中区域固定。填充模式在原适配、缩放及焦点基础上缩小采样区域，保持既有裁切方向。
- 边缘柔光：默认强度 45%，可调 0–100%；按图标主题色绘制向内衰减的柔光，缺少主题色时用中性蓝色。共用外框圆角，不产生外部阴影或改变选中标记。
- 单次扫光：默认强度 22%、时长 450 ms；强度可调 0–100%，时长 150–1500 ms。每次进入播放一次，停留不循环，移出取消，再次进入重新播放。白色斜向光带仅作用于图片，按相同源图裁切和透明度遮罩，保留透明留白。
- 三项均支持原始图、替换图及图片填充（含 Steam）。缩放和柔光默认进入 120 ms、退出 96 ms，不使用标题延迟；扫光使用独立时长，全部服从宿主动画速度及帧率。
- 静止、零强度、不可见、拖动及尺寸调整时不维持动画刷新。减少动画时关闭缩放和扫光，柔光瞬时切换；这些效果不显示标题。
- “交给 xx 处理”的绿色提示按鼠标实际命中的大图标外框和圆角绘制，包括非起始格；不使用单格槽位或单格拖拽虚影的尺寸。普通图标、Dock 和组件的提示保持原几何。

## 6. 配置与兼容边界

将实例数据按职责归为 `frame`、`background`、`foreground`、`effect`，素材服务仍负责引用、下载、解码及缓存；实际字段名在实现前确定。

- `frame`：期望跨度、独立圆角。
- `background`：背景样式、组件预设/自定义材质、共享渐变描述、填充来源及裁切、Steam 策略；识别结果是素材派生状态，不替代用户设置值。
- `foreground`：原始或替换图片、比例、手动位置。
- `effect`：无效果/3D/动态标题/轻微缩放/边缘柔光/单次扫光及选中效果的参数。
- 新效果保留配置版本 2，`effect` 增加 3–5，独立持久化 `zoomAmount`、`glowStrength`、`shineStrength`、`shineDurationMs`。缺失时分别使用 .04、.45、.22、450，保留旧效果及原有强度。宿主、私有设置 IPC、布局与完整备份共用此编解码；不改变 Lua API、组件清单或 `apiVersion`。较旧构建会拒绝新的效果取值，回退前应切回旧效果并保存完整备份，不能承诺旧版无损重写这些配置。
- 当前活动模式与各模式已保存的值分别保存，切换回来可恢复先前设置。
- 这不是仅调整页面：涉及组件背景接入、前景与背景素材拆分、标题绘制层删除和新增效果状态，需要显式迁移旧 `LargeIconConfig`。
- 保留期望跨度、独立圆角、原项目身份与素材；旧封面/自选填充图迁入背景，旧左移标题映射为动态标题向左，旧浮动标题关闭。
- 对旧手动背景及不能一一对应的效果先列迁移表，明确保留值和按本轮要求淘汰的行为，再编写迁移代码；不能简单套新建默认值覆盖全部实例。
- 布局根版本保持。本轮不重解释旧预设值：新增两个预设值，旧默认背景在编辑时迁入适用预设或自定义。
- 组件渐变涉及全局外观、单实例自定义值、现有组件预览、宿主渲染、备份及已有主题读取方。实现前需要盘点现有 `gradientEndA` 在主题读取和组件设置中的使用，保留旧字段语义及缺少新字段时的旧外观；不能直接用全框双色渐变重解释旧“底部渐变”。大图标不因此恢复已删除的常驻预览。
- 本版不预先承诺新增 Lua API。若共享主题返回值、组件清单可写项或其行为需要扩展，须在实际编辑前明确列出公共 API 变化、受影响组件、feature/capability 或版本要求及旧宿主降级路径；仅宿主内部和设置私有数据扩展则保持现有组件 API。
- 修改存储格式前按仓库规则再次说明读取方、降级限制和完整备份方式。
- 解锁判断仍由宿主统一处理。失效后现有实例正常使用、不能改专属设置，仍可还原普通图标；打开目标、容器退化及备份资源规则沿用原规划。

| v1 状态 | v2 行为与保留值 |

布局根版本不变，大图标对象版本为 2。新增可选 `fillScale` 和 `autoTitleDirection`；缺少时分别采用 100% 和旧配置的手动方向，新增实例默认自动方向。旧宿主会忽略新增字段。组件全局外观增加可选 `panelGradient` 对象，单实例外观将同一描述保存到宿主私有 `__panelGradient` 键，设置私有 IPC 版本升到 5；Lua 接口及组件 `apiVersion` 保持不变。缺少或损坏的实例渐变回退为关闭，不改变旧底栏渐变；现有组件预设关闭整框渐变并保留其配色供后续自定义。首次写入 v2 大图标布局前，创建独立的 `LargeIconV2UpgradeBackup` 完整备份；已有 `LargeIconUpgradeBackup` 不能代替它。两个备份不被后续普通保存覆盖。

回退旧宿主使用相应升级前完整备份；重新升级使用新版完整备份恢复。旧宿主不能保证保留新增字段，不承诺旧版编辑后的布局仍能无损恢复本版外观。

3D 实现依据 [Direct2D 3D transform](https://learn.microsoft.com/en-us/windows/win32/direct2d/3d-transform) 和 [Composition Visual](https://learn.microsoft.com/en-us/uwp/api/windows.ui.composition.visual)：内容投影与原生模糊面板需使用等价的矩阵和几何，实际对齐仍需运行时证据。

## 7. 实施顺序与验收

1. 固定上述页面职责、3D 定义及迁移表；接入以图标设置为父页的二级导航，移除占格尺寸和常驻预览，统一设置数据与适用性规则。
2. 扩展组件背景渐变描述与编辑器，保留旧渐变兼容；接入大图标跟随/固定预设和独立圆角，完成默认纯色、图标底色预设及图片填充。
3. 拆分背景与前景素材，重建图标设置，保证模式切换可恢复且不串图。
4. 删除全部桌面大图标悬浮标题路径，完成动态标题两个方向及可用性判断。
5. 验证并实现选定的 3D 方案，统一动效、缩放停绘和拖动静止姿态。
6. 完成全语言文案、标准构建和与边界相匹配的测试，按仓库规则保存待实机验证的双语 try 提交。

验收重点：同预设与组件材质一致；切换全局背景时只有跟随实例变化；圆角不被预设覆盖；底色预设条件显示且不透明填充，默认纯色不自动取色；图标取色按钮只修改当前颜色，组件选择器不出现该按钮；手动渐变的颜色、方向、范围及色点在预览、组件、大图标和重启后相同，旧底部渐变保留原语义；图片填充时组件底色、模糊层和前景图标均消失，透明源图没有残留底板，填充模式禁用动态标题；普通图默认放大裁切且 Steam 使用读取到的背景；Steam 与本地图片入口正确联动；背景和前景图片独立；左/上标题各自置灰、居中、无衬底；任何大图标模式均无外部悬浮标题；3D 不产生材质或命中错位；锁定、重启、备份恢复与旧配置迁移保持合法状态。

导航与控件验收补充：设置进程首次启动后从桌面右键直达、已有设置窗口中直达、设置页内进入均可返回图标设置；重复打开同一实例或切换实例不产生重复历史；返回后恢复父页位置；页面没有占格尺寸和常驻预览；连续数值滑杆、数值输入和逐项恢复保持同步；左右/上下位置独立且默认居中，图标不越出外框；裁切轴无余量时不可调，不显示九宫格或另一个裁切编辑入口。

本轮实施与实际验证以对应提交记录为准；编译和自动化通过不代替桌面实机验收。

### 本轮交互校正

- 动态标题仅支持非图标填充的独立图标层。图标填充下选项置灰、参数隐藏、已有标题动画停止；保留参数供切回图标层后使用。
- 图标增大时先缩短空隙与边距；图标在垂直于移动方向的一边可贴近外框，不因预留文字边距而误禁用。仍保持图标尺寸，不强行缩小。
- 3D 鼠标跟随使用最长 65 ms 的缓出，退出最长 100 ms，不叠加悬停延迟，仍服从全局动画速度与减少动画设置。
- 大图标拖到无效落点时按原跨度显示与组件相同的红色提示；混合选择保留相对偏移，拒绝落点后状态不变。
- 文件选择器由设置进程以设置窗口为所有者打开；宿主只接收路径并执行授权验证和异步导入。首次选图等待期间重绘不得替换导入请求。
- Steam `.url` 非填充模式优先读取 `IconFile` 与 `IconIndex`，支持相对路径、环境变量与 ICO 最大有效帧；不使用封面替代原图。

### 右键快捷入口与新建尺寸

- “大图标设置”下含“背景设置”“视觉效果”“详细设置”。背景预设与设置页使用相同选项；当前项勾选。选择自定义时恢复已保存外观，保存成功后打开详细设置；创建大图标仍不打开设置。
- 视觉效果单选“无效果、3D 效果、动态标题、轻微缩放、边缘柔光、单次扫光”；方向、幅度、时长、字号、粗细、颜色按所选效果在详细设置中调整。首次动态标题默认自动方向，后续保留设置。
- 图标填充禁用动态标题。未解锁不能快捷修改，原有使用及还原行为保留；宿主在菜单返回后重新检查身份、授权、容器状态和保存结果。
- 普通项目和 Steam 新建均为 `1×1`，转换不弹设置。旧配置显式跨度保持；缺失跨度按旧格式的 `2×2` 默认读取。
- 实机需复测默认纯色、底色预设条件显示、各色快捷按钮、自定义层级、右键勾选与设置同步，以及 Dock 和任务栏的多色渐变、材质、方向、动态规则和关闭恢复。


### 组件与任务栏自定义背景的统一层级

全局组件、单个组件和任务栏均采用“颜色与填充”“材质”“边框”标题分组，不使用折叠面板。开关与模式选择直接披露支持的子项。组件边框组含边缘高光，标题为“边框与高光”。原底栏渐变单列，不与整个背景的渐变混用。大图标维持相同的前三组结构。

| 设置组 | 大图标自定义 | 全局组件 | 单组件自定义 | 任务栏默认外观及三个动态规则 |
|---|---|---|---|---|
| 颜色与填充 | 纯色颜色、不透明度；渐变起止颜色、交换、角度、整体不透明度、更多渐变设置 | 纯色颜色、不透明度；渐变起止颜色、交换、角度、更多渐变设置 | 同全局组件 | 同全局组件 |
| 更多渐变设置 | 起止透明度、起止范围、中间色标的颜色/透明度/位置、增删色标、恢复 | 同左 | 同左 | 同左 |
| 材质 | 普通、毛玻璃、亚克力、毛玻璃模糊半径 | 毛玻璃开关、模糊半径、亚克力开关 | 毛玻璃开关、亚克力开关；模糊半径沿用全局 | 毛玻璃开关、模糊半径、亚克力开关；内容主题保留在外观主层 |
| 边框 | 开关、颜色、透明度、宽度；高光开关、宽度和强度 | 颜色、透明度、宽度；高光开关、宽度和强度 | 同全局组件 | 颜色、透明度；宿主尚未支持任务栏边框宽度、高光和圆角 |
| 底栏渐变 | 不显示 | 启用、末端透明度；整框渐变时起始透明度也归入此组 | 末端透明度；整框渐变时起始透明度也归入此组 | 不显示 |
| 文字 | 独立文字颜色组 | 独立文字颜色组 | 独立文字颜色组 | 文字颜色保留在外观主层，适用于预设和自定义 |

任务栏的填充设置作用于默认外观、可见窗口、最大化窗口、Shell 界面三种规则，各自保存，使用同一渐变编辑器。切换纯色保留上次渐变参数；停用页面前提交连续预览，更换会话时丢弃旧会话未提交值。

`SnowDesktop.dock.json` 新增四个可选对象：`taskbarPanelGradient`、`systemTaskbarVisibleWindowPanelGradient`、`systemTaskbarMaximizedWindowPanelGradient`、`systemTaskbarShellUiPanelGradient`。缺少字段按渐变关闭读取；无效渐变拒绝写入且不会部分覆盖其他规则。旧版忽略新字段并可能在保存时丢弃，回退前保留新版完整备份。无新增 Lua API、IPC 字段或 capability，不调整组件 apiVersion。


### 主题与材质中的独立主题卡片

- 快捷面板主题、弹窗主题：全局主题绑定的预设（新配置默认）、深色、浅色、亚克力深色、亚克力浅色、自定义。固定预设独立生效，不再只在全局自定义时生效。全局自定义时，“绑定预设”直接展开自定义项；未调节前使用全局完整外观，调节后保存该面板的独立外观。全局切回预设后恢复绑定，保留已保存的自定义值。
- Dock：跟随组件主题（默认）、深色、浅色、毛玻璃深色、毛玻璃浅色、亚克力深色、亚克力浅色、自定义。背景、文字和浮动 Dock 原生材质统一读取独立外观；圆角继续沿用组件布局设置。
- 任务栏：“主题”行右侧超链接跳转原有任务栏设置页，包含默认外观及动态规则，不重复编辑器。
- 右键菜单卡片放在快捷面板主题卡片前。自定义在当前卡片展示颜色与填充、材质、边框与高光、文字标题组；切回预设保留自定义值。快捷面板和弹窗保留各自窗口圆角与布局。
- 通用配置增加 `quickNavigationAppearance`、`collectionPopupAppearance` 对象，含 `mode`、`customized` 和 `appearance`。新建默认 mode=-1 跟随全局；旧文件缺少字段时使用内部 mode=-2 保留旧条件覆盖语义。0..3 为原四个预设，4 为自定义；旧的 `quickNavTheme` 和 `collectionPopupTheme` 保留用于兼容读取。
- Dock 配置包含 `followComponentAppearance`、`customAppearance` 与可选的 `dockAppearancePreset`（缺省为自定义，兼容原跟随开关）。主设置私有 IPC 版本为 7，宿主和设置子进程必须同步更新；任务栏 Hook 仍为既有 v6。无 Lua API、capability 或组件 apiVersion 变更。旧版本会忽略且可能丢弃这些字段，降级前保留新版完整备份。

### 右键菜单连续调节

大图标的背景预设与视觉效果，以及显示设置中的间距、标题字号、列表字号、字重和行列调节，应用后保留当前菜单及子菜单。勾选、数值、可用状态即时刷新，鼠标位置、键盘选择和滚动位置保持。行列调整直接作为显示设置的子菜单，含当前尺寸与推荐尺寸；达到 1 或 50 的边界时相应增减项禁用。详细设置及自定义背景打开设置窗口时正常收起菜单。原有 Shell 操作仍保持原来的关闭行为。

### 大图标显示与圆角继承

大图标设置和右键设置菜单均提供“仅在悬停时显示”“隐藏桌面时保留”，默认关闭，调节后菜单保持打开。悬停显示复用组件规则：指针进入、选中、键盘交互和拖动期间可见；离开且没有保留交互后隐藏。开启隐藏桌面时保留后，仍能命中、打开、右键、拖动和调整尺寸；两个开关同时开启时继续遵守悬停规则。未保留项目不能在隐藏桌面时被命中或键盘选中。

新增“跟随组件圆角”开关，新建默认开启；关闭后显示比例滑杆。运行时跟随组件当前圆角及 DPI，独立比例继续保存。存量项目缺少该字段时保持独立圆角，可主动开启跟随。`LargeIconConfig` 增加可选布尔值 `showOnHoverOnly`、`keepWhenDesktopHidden`、`followComponentRadius`，保留自身版本 2 和现有布局根版本；缺省均为 false，以免改变存量外观。沿用现有宿主授权检查，失效不清除存量配置。旧宿主忽略且可能丢弃新增字段，回退前保存新版完整布局备份；无 Lua API 或 capability 变更。

隐藏桌面时，保留的大图标可拖到空网格，已隐藏的普通图标不可作为拖放目标。外部文件只能交给可见的保留图标处理，不能落到隐藏桌面的空位。大图标整个外框支持 Shell 拖入处理，多格图标不只接受左上角占格的落点。

### 系统图标菜单

此电脑、控制面板、回收站等 Shell 命名空间图标使用宿主自定义菜单，可转换为大图标。单选时从当前系统 Shell 菜单按规范动词提取“管理”“清空回收站”“映射网络驱动器”“断开网络驱动器”和“属性”，仅提供当前对象实际支持的命令，沿用系统名称与禁用状态；其他命令在“更多选项”中保留。执行由原始 IContextMenu 及 Shell site 完成，不绕过系统确认或 UAC。目录、文件、命名空间的复制、删除及隐藏权限仍按原有规则判断。规范动词接口参考 [Microsoft IContextMenu 文档](https://learn.microsoft.com/en-us/windows/win32/shell/how-to-implement-the-icontextmenu-interface)。

此电脑、用户文件、网络、控制面板、回收站的宿主菜单不提供隐藏或删除；Dock 中只允许移除入口，桌面源不受影响。显示与隐藏通过托盘桌面图标开关管理，写入成功后清除该图标的内存覆盖，后续以 Windows 注册表为准，避免重新显示仍被旧隐藏缓存过滤。第三方命名空间保留既有隐藏行为，并使用相同的状态写入规则。
