## 信息结构与视觉

- 一级标签为“操作教程 / 个性化设置”。操作教程按基础、文件、Dock、组件分主题；个性化设置按 12 个功能模块检索。
- 使用原生 SelectorBar、按钮和有最大高度的 ListView。列表只显示标题、短介绍和操作，点标题展开详细内容；每个列表只展开一项。窗口较窄时操作按钮换行，详细内容随列表滚动。
- 图标复用仓库的官方 Fluent 资源；保留系统高对比度字形回退。主题颜色沿用 WinUI 资源，桌面文字跟随系统文本缩放。
- “个性化设置”只提供“打开相关设置”，不开始练习，不执行更新；用户自行选择是否更改配置。

## 11 项独立操作教程

| 主题 | 教程 |
| --- | --- |
| 基础 | 用集合收纳应用；移动和调整组件大小；创建集合组 |
| 文件 | 桌面文件；文件夹映射；创建文件组 |
| Dock | 固定应用；创建映射；放入集合；放入文件来源 |
| 组件 | 添加 Lua 组件 |

每项可以使用已有组件，需要新建时提示通过桌面右键菜单添加并先查看预览。集合组、文件组把拖到同类组件上并按住 Ctrl 松手的操作列为主要路径，保留先添加空组再放入来源的替代路径。桌面文件的分类规则归入个性化设置，不作为练习步骤。

Dock 文件区说明包含桌面文件组件、文件夹映射、真实文件夹、文件夹快捷方式，以及从资源管理器直接拖入创建快捷方式入口。核对依据为 `app_dock_drop.cpp`、`app_dock_model.cpp`、`app_external_slot_drop.cpp` 和 `app_drop_execution.cpp`；外部目录保留原位置，实际文件操作仍作用于来源。本轮没有改变拖放业务逻辑，桌面验收仍待用户完成。

## 桌面浮动说明

- 删除完成、暂停/继续、下一教程、跨主题、准备检查等学习流程与 IPC 状态。仅保留当前打开的说明和阅读页码，关闭后不恢复，不记录完成历史。
- 浮动面板复用桌面前景层，拖动顶部手动定位；菜单是更高层的原生弹窗，打开菜单不会改变面板位置。不再根据菜单、预览、Dock、组件或拖放落点自动避让，也不跟随鼠标切换显示器。
- 位置使用屏幕坐标，只在本次进程内保留。用户拖动可跨屏；工作区域缩小或说明变高时仅作边界约束，确保面板可操作。
- 更多菜单只查看/收起详细说明及长内容翻页。末尾保留“返回指南”和“收起”，不切换到其他教程或主题；相关设置按需出现。取消菜单不改内容与位置。
- 面板内普通点击、双击、中键、滚轮和右键不穿透到桌面对象。拖动标题使用宿主指针捕获，松手或失去捕获停止移动；不抢焦点。

## 重复临时初始化反馈（2026-09-16）

`8703a3f7` 之后的用户验收仍未通过，已用 `1c667933` 记录失败：第一次实验没有读取原生布局，之后切换引发设置崩溃，重新打开时临时初始化开关仍开启，关闭后桌面恢复且调试入口消失。

本轮依据及调整：

- 两个原始设置进程转储（PID 28868、35904）都落在 `SettingsShell::FocusPendingTarget + 0x4a0` 调用 WinUI `Focus` 的位置，异常为 `0xC0000005`。引导路由现在选中指定内容并滚动到通用页顶部，不再登记或强制聚焦 SelectorBarItem。普通键盘访问保留；同页跳转也会更新基础/探索选择。
- 主动状态推送与按设置快照请求的状态曾混用独立计数及控制器修订号，后者还会覆盖发布者版本。现在由宿主统一生成完整状态与递增版本，设置侧保留该版本，避免把新状态当作旧值丢弃。
- 从正在进行的实验恢复设置时，调试入口按本次设置会话保留。关闭实验不会移除当前调试页；正常的新设置会话仍遵守原有解锁规则。
- 首次失败日志为 `HRESULT=1`（`S_FALSE`）。原生视图读取针对 `S_FALSE` / `E_PENDING` 在原来的 2500 毫秒预算内等待就绪；永久失败立即返回，预算耗尽仍使用默认布局。不更改 Explorer 图标位置、显示设置或用户文件。失败日志增加阶段和尝试次数；`S_FALSE` 的不完整快照不能当作成功。
