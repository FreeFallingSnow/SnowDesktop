# 通用页新手引导

引导位于“常规”页顶部、启动设置之前，不再提供独立“开始”导航。保留“基础 / 探索”，旧首页路由兼容转到常规页，不改变显示资格。

## 基础与练习

四个原生按钮以 24 DIP 节点和细线连接，点击区域至少 40 DIP。内容宽度不足 560 DIP 时改为纵向排列。只展示所选步骤说明，点击节点只回看；全部完成后收为“基础已完成”，可查看步骤及探索。配色使用 WinUI 主题资源。

节点使用完整圆角和四边边框，未选中节点增加中性填充，数字和步骤标题采用半粗字重。“去桌面练习”（完成后为“查看步骤”）与“不再显示”放在同一操作行。

| 任务 | 真实操作及完成条件 |
| --- | --- |
| 添加集合 | 桌面空白处右键 → 添加组件 → 集合。菜单直接添加或预览后添加成功才记录练习集合 ID。取消、失败、没有空位、程序直接添加均不完成。 |
| 拖入应用 | 先说明集合是收纳应用的组件，再提示拖入应用。应用图标实际新增到练习集合中才完成；普通文件、其他集合、重排、悬停及取消均不完成。 |
| 移动与缩放 | 拖动集合底部或按住中键移动，再拖动右下角调整大小。位置和尺寸分别实际改变才完成；取消和原地松开不计入。 |
| 桌面文件 | 再次从右键菜单添加桌面文件组件，创建成功即完成。随后说明它用于收集散落的桌面文件、可以添加多个，以及文件夹映射可显示其他文件夹；保留右键按需开启“自动收集”的提示，不要求或自动开启。 |

“去桌面练习”只收起设置并开启随步提示，不创建组件或替用户打开菜单。提示使用桌面已有绘制层，无普通提示的超时计时器，真实操作后自动推进；按菜单、子菜单与组件预览的实际窗口边界，以及练习组件和拖放位置避让。只有提示的“收起 / 返回设置”按钮参与命中；收起暂停本轮提示，永久关闭使用设置中的“不再显示”。练习集合丢失、进入组或 Dock 时，重新引导用户从右键菜单添加独立集合，保留学过的步骤。

四项全部完成后，“返回设置”改为“探索更多功能”，点击直接进入常规页的探索标签；只完成桌面文件一项时仍返回基础。最后一步的用途说明持续保留，回看已完成的桌面文件步骤也显示这段说明。

## 探索

探索使用可点击的导航卡片，每张包含图标、标题、介绍和跳转箭头，复用原有设置卡片样式。集合卡片回到添加集合教学，其余卡片连接文件分类、Dock、快捷导航、页面、外观、组件及备份设置，不复制设置控件。组件和高级功能仍遵守原有可用性规则。

彩色图标复用现有设置资源；快捷导航使用相同固定版本的官方 Fluent Search 24 Filled + Regular 原始路径，映射见 `assets/settings/icons/README.md`。高对比度切换到系统字形，变化通知回到设置 UI 线程更新，关闭页面后不再执行排队更新。

## 初始化、迁移与关闭

- 仅实际进入桌面初始化流程时启用，包括清空布局后的重新初始化；原生桌面提取失败、回退默认布局仍适用。普通启动、升级、刷新、恢复有效备份或显示器变化不以这些事件本身触发。
- 初始化后请求打开常规页并定位引导一次。关闭设置只消费首次定位状态，未关闭的引导留在常规页。
- “不再显示”立即隐藏整个区域，并把永久关闭决定保存到私有 `SnowDesktop.onboarding.json`。之后启动、升级、重新初始化均尊重关闭决定。
- 私有状态版本 2 区分显示资格、永久关闭、首次定位及进度。版本 1 迁移保留完成记录；旧 `welcomePending=false` 不等于用户关闭，也不因此启用引导。旧待显示状态可继续展示。缺少进度文件及普通操作记录不会把老用户当新用户。
- 数据损坏时保留原文件、记录诊断并停止正常引导写入和初始化启用，避免覆盖未知的关闭决定。
- “调试 → 临时初始化”每次使用全新的内存进度和显示状态。引导区域不额外显示调试通知条；关闭实验或重启恢复正常状态，实验中关闭引导不影响正常用户。
- 仅内部宿主、设置 IPC 和私有持久化调整，没有新增公共组件 API，也没有修改布局 schema。
