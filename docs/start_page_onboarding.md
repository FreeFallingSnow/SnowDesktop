# 通用页使用指南

使用指南常驻通用页顶部、启动设置之前。首次使用默认展开，此后只保存整个面板的展开或折叠选择。教程可任选，连续练习的位置仅保留在当前进程；没有完成历史或特定组件绑定。

## 页面和视觉

- 外层原生 Expander，按基础、文件整理、外观、Dock、快捷导航、组件与备份分组。
- 同主题使用原生 ListView，通常展示约四到五行；高度随窗口调整，超过上限后由列表自身滚动，不再用下拉框选择教程。
- 每行包含已有官方 Fluent 图标、标题、最多两行用途、直接操作入口。点击标题区域展开完整说明，同一时刻只展开一项；详细步骤和提示随整个列表滚动。
- 宽度不足时，操作按钮移到文字下方；文字可换行，行高由内容决定。使用主题文字资源、原生按钮反馈与高对比度图标回退。
- 当前练习显示文字标记；返回指南定位当前项，同主题不重建列表。标签切换不改变正在进行的练习。
- 所有图标复用已有官方资源，没有手绘 SVG。没有新增公共组件 API。

## 连续桌面练习

- 点击练习只隐藏设置并显示提示，不创建组件、不打开添加菜单、不启用功能。
- 桌面提示显示主题、当前序号、标题、短说明和下一项名称。序号表示主题内的位置，不代表已学会的数量。
- “已完成，下一项”由用户主动推进；普通桌面操作不记录完成，也不自动换课。
- 最后一项使用“完成本项”，随后提供明确的下一主题入口；不自动跨组，不宣称中途开始或跳过的课程已经全部完成。
- “更多”提供完整步骤、上一项、跳过、结束练习；详细文字按 DirectWrite 的实际行边界分页，通过菜单翻页，不拦截桌面滚轮。
- “收起”暂停本轮提示；“返回指南”暂停并定位当前教程；再次点击当前行“继续练习”恢复同一项。结束练习才清除本轮位置。
- 设置型教程直接定位对应设置，桌面图标隐藏时仍可使用。当前练习保留，关闭设置后在桌面可见时恢复提示，可继续下一项；相关设置按钮不会自动修改任何配置。
- 提示使用主题配色、标题和辅助文字层级及突出的主操作；只拦截按钮区域，避开菜单、组件预览、操作中的组件、拖放落点和 Dock。

## 前置准备与生命周期

前置条件仅检查当前桌面和配置，允许使用任意满足条件的组件。条件不足仍可进入教程，在同一桌面提示内展示准备操作。Dock 先检查启用状态，再检查独立来源组件；分组检查当前独立组件数量。需要开启功能时提供现有设置入口。

准备完成后第一次点击“准备好了，继续”仅返回原教程说明，不完成原教程。后续手动完成才推进；准备期间发生组件删除或配置变化时重新检查。开始操作后不重新要求独立来源，避免集合已移入组或 Dock 后无法手动完成。明确“跳过”允许离开无法立即练习的项目。

- 私有文件 SnowDesktop.guide.json 仍只保存版本和 expanded；不记录当前项、历史、组件 ID。
- 不读取、修改或删除原 SnowDesktop.onboarding.json。
- 新进程没有活动练习，不自动恢复桌面提示。实际初始化后仍定位通用页一次；普通启动、刷新、恢复和显示器变化不触发定位。
- 临时初始化切换结束练习，保留折叠偏好；旧 Home 和 start.basics / start.explore / start.layout 路由兼容。
- 私有设置 IPC 版本更新为 9，传递当前教程标识；旧版本进程在解释不同结构的状态前断开连接。

## 重复临时初始化反馈（2026-09-16）
