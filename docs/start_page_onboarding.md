# 通用页使用指南

使用指南常驻通用页顶部、启动设置之前。首次使用默认展开，此后只保存用户对整个面板的展开或折叠选择。独立“开始”导航和有完成进度的四步流程已经移除。

## 页面与教程

外层使用原生 Expander，内部按主题使用 SelectorBar 标签页。每个主题内通过“选择教程”切换具体指导，显示用途、准备条件、编号操作、提示及操作按钮。没有完成标记、解锁顺序或自动跳到下一课。

## 桌面练习和前置条件

“去桌面练习”只在明确点击后隐藏设置并启动宿主简短提示，不创建组件、不打开菜单、不设置开关。每次只提示所选教程；不会检测完成或自动推进。

“收起”结束本次提示。“返回指南”结束提示并打开通用页中原来的主题和教程，用户自行选择下一项。桌面提示只在当前进程中存在，重启后不恢复。

前置条件由当前桌面和设置计算，不使用历史记录或特定组件 ID。设置页显示缺少的条件和准备入口；点击练习时宿主重新检查。Dock 教程先检查 Dock，再检查来源组件；准备按钮进入已有设置或对应基础教程，不自动代办。桌面未就绪、被隐藏或正执行冲突操作时保留设置页并说明暂不可用。

宿主提示持续显示，避开菜单、预览、正在操作的组件、拖放区域和 Dock 内容。仅两个按钮区域拦截指针，不抢焦点；设置可见时不绘制桌面提示。完成与否由用户判断，最后的用途和可选说明不会被完成提示覆盖。

## 偏好、初始化与兼容性

- 私有 `SnowDesktop.guide.json` 仅保存版本和 `expanded` 布尔值；原子写入，写入失败时恢复先前选择并提示。
- 不读取、不修改、不删除原 `SnowDesktop.onboarding.json`。旧完成进度和“不再显示”不会隐藏新的常驻帮助，也不会被转换为新的教程状态。
- 实际首次初始化完成后仍定位通用页一次；普通启动、刷新、恢复与显示器变化不据此自动打开设置。重新初始化只安排本轮定位，不重置用户折叠选择。
- 临时初始化继续使用已有布局隔离机制；不再有独立的教学进度。开关切换结束本次桌面提示，折叠偏好与普通使用一致。
- 显式从搜索、准备入口或桌面返回教程时，可临时展开面板供查看，不写入用户偏好；手动折叠/展开才保存。初始化定位尊重已保存的折叠状态。
- 旧 Home 路由仍转入通用页；`start.basics`、`start.explore` 和 `start.layout` 保持内部兼容。没有公共组件 API 变更。

## 重复临时初始化反馈（2026-09-16）

`8703a3f7` 之后的用户验收仍未通过，已用 `1c667933` 记录失败：第一次实验没有读取原生布局，之后切换引发设置崩溃，重新打开时临时初始化开关仍开启，关闭后桌面恢复且调试入口消失。

本轮依据及调整：

- 两个原始设置进程转储（PID 28868、35904）都落在 `SettingsShell::FocusPendingTarget + 0x4a0` 调用 WinUI `Focus` 的位置，异常为 `0xC0000005`。引导路由现在选中指定内容并滚动到通用页顶部，不再登记或强制聚焦 SelectorBarItem。普通键盘访问保留；同页跳转也会更新基础/探索选择。
- 主动状态推送与按设置快照请求的状态曾混用独立计数及控制器修订号，后者还会覆盖发布者版本。现在由宿主统一生成完整状态与递增版本，设置侧保留该版本，避免把新状态当作旧值丢弃。
- 从正在进行的实验恢复设置时，调试入口按本次设置会话保留。关闭实验不会移除当前调试页；正常的新设置会话仍遵守原有解锁规则。
- 首次失败日志为 `HRESULT=1`（`S_FALSE`）。原生视图读取针对 `S_FALSE` / `E_PENDING` 在原来的 2500 毫秒预算内等待就绪；永久失败立即返回，预算耗尽仍使用默认布局。不更改 Explorer 图标位置、显示设置或用户文件。失败日志增加阶段和尝试次数；`S_FALSE` 的不完整快照不能当作成功。
