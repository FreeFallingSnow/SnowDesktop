## 本轮调整

- 未初始化桌面 PIDL 时使用显式空 IDLIST（桌面根），避免空指针代表的全局订阅。
- 启动局部结果与完成结果向 UI 发送合并通知，减少等待两秒维护轮询；保留交互、版本和销毁隔离。
- 映射入口图标失败不再发布 -1 为永久成功；保留已有效的图标，没有有效图标时显示文件夹兜底，并在五秒后允许重试。
- 后续调整使用现有两秒维护定时器唤醒到期的 Dock 图标重试，静止不动时也能继续；五秒退避后，下一个维护轮次触发重绘，不承诺精确五秒完成 Shell 查询。
- 启动本地条目直接生成隐藏 `.lnk` / `.url` 后缀的显示名，文件路径和布局标识不变；不裁剪普通文件或同名目录后缀。
- 增加启动快照过期和映射首图投递诊断。

## 验证范围

- 原始现场证明上述两处故障存在；新版本的桌面视觉和实际启动耗时仍需用户验证。
- `slot_runtime_contract` 定向通过。使用真实 Shell 注册和独立消息窗口：全局监听对照收到隔离临时日志更新，生产启动监听没有收到该无关更新。
- 独立负向对照：恢复空指针全局订阅、去除完成通知、永久缓存失败、恢复原始快捷方式文件名，四种变异均成功编译并由相应行为断言失败；候选对照通过。生产源码未为变异改回旧实现。
- 失败重试缓存使用可控时间，覆盖退避、成功恢复、保留旧图标、过期任务及已移除入口。后台通知测试覆盖分批、完成再唤醒和停止后的结果拒绝。
