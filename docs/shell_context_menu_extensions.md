# 系统右键菜单同步与二次隐藏

设置 → 右键菜单保留菜单样式选择，并以“文件 / 文件夹 / 文件夹空白处 / 桌面”
四个场景展示系统实际返回的菜单。每行只有原始图标、名称和显示开关。
优先使用系统提供的图标；缺图且名称精确匹配扩展注册项时，只读加载原模块的小图标资源，
仍无资源时设置列表使用通用图标。系统已禁用或当前对象不适用的项目不会被自行加入。

默认跟随系统，不再要求手动勾选扩展组或指定放置位置。原始菜单项直接接入自绘
右键菜单，保留第三方自身的级联关系；例如根菜单直接显示“7-Zip”，不增加
“系统扩展”和“7-Zip Shell Extension”包装层。第三方项目位于“展开更多选项”
上方，与它同组，中间不额外插入分隔线。宿主已有的文件操作与桌面操作
继续由宿主处理，避免重复菜单和绕过应用内文件操作语义。

## 设置与对象范围

开关仅追加或移除 SnowDesktop 的隐藏记录，不修改系统注册表，也不启用系统已禁用的扩展。
四个场景独立保存。菜单调用时重新取得实际对象的系统菜单，再应用相应隐藏记录。
混合选择文件和文件夹时，两类中的隐藏记录均有效。

设置页使用隔离的普通文本文件/文件夹读取默认列表，桌面页读取真实桌面背景菜单。
无需先选样本；涉及特定文件类型、版本库或网盘的项目，可通过页底的可选入口查看
具体文件/文件夹。进入其他场景或刷新会重新查询。查看过程不执行任何菜单命令。

隐藏项优先使用 canonical verb 标识。没有唯一 canonical verb 时使用名称和子菜单
命令签名；这类项目更改语言、名称或命令结构后可能需要重新隐藏。旧版实验选择器的
enabled / selections 字段为兼容回存而保留，运行时不再用它们控制启用和嵌套位置；
新的 hidden 数组保存实际生效的场景隐藏记录。

## 系统查询与进程边界

--shell-menu-helper 是内部同源子进程模式，不是公共 CLI。组件公共 API 不变。
查询从实际 Shell 文件选择或背景的 IContextMenu 聚合对象获得菜单，不再逐个
实例化注册表中的处理器。系统可见性、LegacyDisable、扩展当前对象条件由 Shell
决定；本地设置只能继续减少项目，不能恢复 Shell 未提供的项目。

菜单、COM 对象、站点和命令映射留在同一子进程中，直到关闭菜单或执行选中命令。
图标同时读取 MIIM_BITMAP 和 MIIM_CHECKMARKS（包括 7-Zip 使用的 hbmpUnchecked），
并支持 Shell 回调位图。7-Zip 默认关闭菜单位图时，补充读取其原模块的 13x13 资源，
不修改 7-Zip 设置。资源模块以 DATAFILE 加载，不执行 DLL 初始化。
图标以有界像素传输，宿主和设置页不接收第三方原生句柄。
文件夹查询前用内核自动删除的隔离文本样本初始化文件关联，以避开本机观察到的
扩展冷启动加载锁；不显示或执行样本菜单。查询仍在同一个有期限的辅助进程内。
查询超过 8 秒终止辅助进程，关闭菜单或切换页面取消会话。级联打开期间仍处理超时，
返回数据待级联关闭后再合入，并保留键盘高亮及屏幕边缘约束。

调用保留原会话、真实命令和当前可用状态。辅助进程有 120 秒上限，允许交接至独立
应用和显示对话框；特殊自绘项目及延迟加载的级联可回退对应原生菜单，查询时不强制
填充所有子菜单。原有“更多选项”沿用已有路径，
不能据此宣称所有 Shell 调用均已隔离。

## 参考与验证边界

交互参考火绒的分类开关列表，以及
[ContextMenuManager](https://github.com/BluePointLilac/ContextMenuManager) 的按场景管理；
直接处理原有菜单项的思路参考
[Nilesoft Shell](https://nilesoft.org/docs/configuration/modify-items)。
7-Zip 图标兼容根据其
[公开实现](https://github.com/ip7z/7zip/blob/main/CPP/7zip/UI/Explorer/ContextMenu.cpp)
及[默认图标选项](https://github.com/ip7z/7zip/blob/main/CPP/7zip/UI/Common/ZipRegistry.cpp)
核对，未复制项目代码。

自动化使用隔离目录和独立菜单窗口；真实 7-Zip 查询不执行其命令。系统禁用回归只创建
唯一的临时 HKCU 文件类型/静态命令，测试 LegacyDisable 的真实 Shell 行为后清除，
不修改现有文件关联、第三方注册项或用户文件。桌面宿主不通过自动化操作。
首版仍以经典 Shell 菜单为范围，Windows 11 仅新式注册项不保证提供。
设置列表视觉、实际桌面/Dock/文件夹映射菜单及第三方操作需用户实机验收。
