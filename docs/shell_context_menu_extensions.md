# 右键菜单扩展与显示设置

设置 → 右键菜单保留菜单样式选择，并以“文件 / 文件夹 / 文件夹空白处 / 桌面”
四个场景展示系统实际返回的菜单。每行只有原始图标、名称和显示开关。
优先使用系统提供的图标；缺图且名称精确匹配扩展注册项时，只读加载原模块的小图标资源，
仍无资源时设置列表使用通用图标。系统已禁用或当前对象不适用的项目不会被自行加入。

扩展项目默认全部隐藏，按场景手动打开所需项目。原始菜单项直接接入自绘
右键菜单，保留第三方自身的级联关系；例如根菜单直接显示“7-Zip”，不增加
“系统扩展”和“7-Zip Shell Extension”包装层。第三方项目位于“展开更多选项”
上方，与它同组，整组固定放在菜单末尾，中间不额外插入分隔线。宿主已有的文件操作与桌面操作
继续由宿主处理，避免重复菜单和绕过应用内文件操作语义。
“展开更多选项”右侧提供独立的“管理”按钮，直接打开右键菜单设置的扩展卡片；
左右两个操作共用一行，鼠标和键盘分别命中，异步刷新时一起保留在底部。

## 设置与对象范围

开关仅追加或移除 SnowDesktop 的显示记录，不修改系统注册表，也不启用系统已禁用的扩展。
四个场景独立保存。菜单先对已有显示快照应用显示记录，再在后台取得实际对象的系统菜单。
当前场景没有任何显示记录时，不启动扩展查询。混合选择文件和文件夹时，项目必须在两类中均启用。

设置页沿用菜单外观卡片，扩展管理使用相同卡片样式，保留图标、分类、搜索、刷新和显示开关。
详细说明放在常规页使用指南的“基础 → 右键菜单设置”，可直接跳转设置并返回原指南条目。

设置页使用隔离的普通文本文件/文件夹读取默认列表，桌面页读取真实桌面背景菜单。
无需先选样本；涉及特定文件类型、版本库或网盘的项目，可通过页底的可选入口查看
具体文件/文件夹。设置页和菜单共用内存与磁盘显示缓存，已有列表先显示再后台更新；
检查同一个具体对象及桌面背景时共享同一条快照，普通文件/文件夹样本有独立键。
刷新使共享快照失效，查看过程不执行任何菜单命令。

显示记录优先使用 canonical verb 标识。没有唯一 canonical verb 时使用名称和子菜单
命令签名；这类项目更改语言、名称或命令结构后可能需要重新启用。旧版实验选择器的
enabled / selections 字段为兼容回存而保留，运行时不再用它们控制启用和嵌套位置；
hidden 数组同样只保留以便回存。新的 shown 数组保存实际生效的场景显示记录；
旧版默认跟随系统的配置不自动迁移为全部显示，首次升级后需选择所需项目。内部设置 IPC 为 17。

## 系统查询与进程边界

--shell-menu-helper 是内部同源子进程模式，不是公共 CLI。组件公共 API 不变。
查询从实际 Shell 文件选择或背景的 IContextMenu 聚合对象获得菜单，不再逐个
实例化注册表中的处理器。系统可见性、LegacyDisable、扩展当前对象条件由 Shell
决定；本地设置只能继续减少项目，不能恢复 Shell 未提供的项目。

菜单、COM 对象、站点和命令映射留在同一子进程中，直到关闭菜单或执行选中命令。
图标同时读取 MIIM_BITMAP 和 MIIM_CHECKMARKS（包括 7-Zip 使用的 hbmpUnchecked），
并支持 Shell 回调位图。7-Zip 默认关闭菜单位图时，补充读取其原模块的 13x13 资源，
不修改 7-Zip 设置。资源模块以 DATAFILE 加载，不执行 DLL 初始化。
图标以有界像素传输，宿主和设置页不接收第三方原生句柄。
首次文件夹查询前用内核自动删除的隔离文本样本初始化文件关联，以避开本机观察到的
扩展冷启动加载锁；不显示或执行样本菜单。查询仍在同一个有期限的辅助进程内。
辅助进程第一次成功查询后重新绑定一次实际对象的菜单，让首次聚合触发的系统打包扩展
目录完成初始化，再发布最终菜单和命令映射；后续查询只绑定一次。此过程无固定等待，
不强制展开级联，仍受同一次查询的 8 秒期限约束。本机冷进程中首次遗漏终端的情况已在
独立真实查询中复现；具体桌面入口的连续操作仍需实机验收。
查询超过 8 秒终止辅助进程。关闭菜单后已开始的查询继续完成并写入缓存，随后释放会话；
设置页切换仍取消旧查询。级联打开期间仍处理超时，
返回数据待级联关闭、鼠标移开菜单项且按钮释放后再合入。更新保持菜单顶部、宽度及滚动偏移；
到屏幕底部后使用原有滚动方式，不重新向上定位整张菜单；从 Dock 上方向上弹出的菜单
以 Dock 上沿为增长边界。键盘选中项按命令身份恢复。

延迟初始化或自绘的原生子菜单在赋予命令令牌前识别，占位空行与省略号不作为自绘子项呈现。
点击其父项后由原生菜单展开实际命令，避免 PowerShell 7 出现额外的“…”层。此类子菜单的
样式由系统和扩展决定，真实展开与执行仍需实机验证。

调用保留原会话、真实命令和当前可用状态。辅助进程有 120 秒上限，允许交接至独立
应用和显示对话框；特殊自绘项目及延迟加载的级联可回退对应原生菜单，查询时不强制
填充所有子菜单。原有“更多选项”沿用已有路径，
不能据此宣称所有 Shell 调用均已隔离。

## 查询缓存与键盘访问键

每个 UI 线程最多保留一个成功查询且未执行命令的空闲辅助进程，最长复用两分钟。
菜单关闭后异步释放原生菜单与 COM 对象，确认释放后删除该会话的隔离样本；后续查询
可以提前排队，但释放确认不会清理新会话的样本。复用时为当前对象重新查询并建立命令映射；不会按文件类型
套用另一文件的菜单，也不把旧命令编号用于新对象。已取消、失败、超时或开始执行的
会话不进入空闲池，同时打开的会话各自拥有进程和菜单对象。

辅助进程缓存按场景查到的图标注册元数据，以及最多 64 个扩展模块的原始位图资源。
模块大小或修改时间变化后重新读取资源。父进程以注册表事件监听文件关联、扩展、
资源管理器策略和应用主题变化，下一次查询丢弃旧进程；手动刷新也会失效缓存。
查询本身继续由真实 Shell 决定项目、禁用状态和命令，首次冷启动仍需加载第三方扩展。

宿主和设置子进程使用同一缓存后端，目录为
`%LOCALAPPDATA%\SnowDesktop\Cache\ShellMenus\<程序路径标识>\`。快照保存文字、图标像素、
访问键、状态与层级，递归清除命令令牌；不保存 COM 对象或原生句柄。读取失败、文件损坏、
版本不符及过期均回退实时查询。固定 36 个槽位、每条最多 2 MiB、最长 24 小时；原子替换
避免并发读到半份文件，同槽冲突只造成未命中。进程内存副本也检查磁盘修改时间。
普通与 Shift 桌面菜单分别保留独立槽位，不会被其他文件菜单碰撞挤出。

实际对象以完整选择、场景、Shift 扩展状态、文件属性/大小/修改时间、程序构建时间和
系统语言区分；目录只记录路径和属性，不因新增或删除子项导致目录修改时间变化就丢弃
显示快照。目录内部状态仍在后台重新查询，执行时始终核对实际命令。缓存不按扩展名给
另一文件套用菜单。网络路径不做同步缓存探测。后台结果写入
前再次检查对象和共享失效标识，旧查询不能恢复已失效的快照。注册事件和手动刷新通过
共享标识同时失效设置页与菜单缓存；缓存过程不修改第三方注册项。

有缓存时直接显示原始扩展项目和图标，随后后台刷新。无缓存时先显示已有菜单，查询
完成后将扩展项目加入“展开更多选项”上方；菜单中不再显示“正在读取”或失败占位。
未变化的项目保留本地编号，以便刷新后保留键盘选中位置；展开级联期间延后替换菜单树。
后台查询失败时，若共享缓存尚未失效，保留已有显示快照；仍可使用“展开更多选项”。

点击缓存项目只保存原始层级、名称和 canonical verb 构成的选择身份。新查询尚未返回
时，在原 STA 上保留有期限的待执行请求，取得当前菜单后再解析唯一命令；已禁用、消失
或有歧义的项目不会执行，禁止把快照中的旧编号交给新会话。没有用户点击时绝不执行命令。
若本轮后台刷新已经失败，明确点击缓存项会重新创建查询会话，再按同一身份核对命令；
失败会话不复用，也不因保留旧显示而直接执行过期令牌。
应用关闭期间的系统变更及扩展内部动态状态可能短暂显示旧快照，后台查询更新显示；
这不等于从磁盘恢复可执行的 Shell 会话。首次新对象仍需后台加载扩展，缓存不承诺消除
第三方本身的查询时间。

原生文字中的 `&` 访问键标记在解码时单独保留，`&&` 保持字面 `&`，不将文件名中的
普通括号或右侧快捷键列猜作访问键。菜单中的唯一字母键立即执行或展开子菜单，重复
访问键循环选中并由回车确认，跳过禁用项目，支持 Alt 字母和大小写匹配。搜索框有焦点时
普通文字仍输入搜索框。原有方向键与无显式访问键的首字母选择行为保留。
按键在消息转换前匹配，避免重复字符动作；输入法产生 `VK_PROCESSKEY` 时使用
[ImmGetVirtualKey](https://learn.microsoft.com/en-us/windows/win32/api/imm/nf-imm-immgetvirtualkey)
取得原始虚拟键。中文输入法的桌面实机效果仍待用户验证。
