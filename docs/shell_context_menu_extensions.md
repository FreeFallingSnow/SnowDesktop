# 自绘菜单中的 Shell 扩展

“右键菜单”设置页集中管理原有菜单样式与可选 Shell 扩展。旧设置中的
`contextMenuStyle` 数值保持不变，旧外观页搜索目标重定向到新页面。
扩展默认关闭；关闭后保留选择。设置只影响 SnowDesktop，不修改 Explorer 的注册项。

## 发现与选择

选择文件、文件夹或文件夹背景作为样本，读取适用于该对象的经典 `shell` 和
`shellex/ContextMenuHandlers` 注册项。列表不是所有文件类型菜单的一次性全集。
首次列出注册项不实例化扩展；“加载命令”在隔离进程中查询所选注册项。

静态命令以注册路径标识来源，通过 Shell 生成的菜单确认命令当前可用；
传统 COM 扩展以规范化 CLSID 标识来源。可可靠获取、且在同一扩展内唯一的
canonical verb 用于逐项选择；无标识、重复标识和特殊自绘项目保留整组入口。
显示文字与本次菜单命令编号不作为持久标识。

每项可隐藏、放入扩展子菜单或放到一级菜单。单项选择覆盖整组选择；
未安装或不适用于当前样本的已保存选择仍保留。实际右键时重新查询适用项目，
不会将样本中的临时命令编号用于另一个对象。预览仅显示，不执行命令。

## 生命周期与隔离

`--shell-menu-helper` 是同一可执行文件内部的子进程模式，不是公共 CLI。
它在单实例检查、桌面、Steam 和看门狗初始化之前分流，复用受限句柄继承、
可执行文件身份验证、独立 Job 和有界 IPC。组件公共 API 不变。

查询异步返回菜单值，宿主不加载第三方菜单 DLL。菜单、COM 对象、站点和命令
映射留在原子进程中，直到关闭菜单或调用命令。图标传输有界像素，不传原生句柄。
查询超过 8 秒终止该辅助进程；关闭或切换样本取消未完成会话。

用户选择命令后，保留原会话进行调用，允许弹出对话框和异步 Shell 交接。
调用辅助进程有 120 秒上限；启动的应用通过 Job 的 breakaway 规则独立存活。
特别绘制的菜单在同一隔离进程中回退原生显示。

“隐藏”是显示选择，不代表枚举时绝不加载相应 DLL。静态命令的 Shell 聚合查询
仍可能接触其他处理器，但这些调用发生在隔离进程内。原有“更多选项”及其他
明确的系统菜单入口沿用已有路径，不能据此声称所有 Shell 调用均已隔离。

## 兼容范围与验收

首版针对经典 Shell 扩展。Windows 11 仅通过打包清单注册的新式菜单项、依赖
完整 Explorer 私有上下文的扩展，以及无可靠 canonical verb 的静态级联项，
不保证出现在自绘列表中；原有系统菜单入口仍可使用。

自动化覆盖配置与 IPC、逐项覆盖和来源区分、有界子进程查询及超时后恢复。
传输测试替代第三方查询，只能证明进程与状态传输，不能证明第三方扩展兼容。
实机验收应使用实际安装的压缩工具、编辑器、网盘，分别检查文件、文件夹、
多选、背景菜单、图标、禁用状态、动态级联、弹出对话框、取消及超时后的再次打开。
桌面、Dock 和组件中的显示效果与真实扩展调用均需用户实机验证。
