# 右键菜单扩展与显示设置

设置 → 右键菜单保留菜单外观卡片，扩展管理分为“文件与文件夹”和“空白处”。
默认隐藏全部第三方扩展；开关只控制 SnowDesktop，不修改系统或第三方配置。
相同身份共用开关，展开“按位置设置”后可选择跟随通用、显示或隐藏。
位置例外优先，混合选择中的明确隐藏优先；最终适用性仍由 Shell 判断。

## 可管理列表与首次发现

注册目录在后台扫描通用位置、文件类型、ProgID、类型分组和打包应用注册，保存稳定身份、
来源及系统禁用状态。原始注册记录仅供关联和失效判断，不直接变成设置控件。
设置页只列出真实查询中出现的可用菜单根项，保留图标和动态子菜单的整体开关。
未观察到可用菜单的“待关联”注册记录隐藏；已观察到但无法可靠关联注册来源的菜单根项，
使用独立菜单身份控制，不凭相同名称猜测归属。同身份合并位置，同名不同身份保持独立。

首次访问设置页会后台查询当前程序文件、其所在文件夹、该文件夹空白处和真实桌面。
注册目录就绪后，继续对已注册且启用的常见类型分批查询单选、同类型多选及各自的 Shift 菜单。
支持 PNG、JPEG、BMP、GIF、TIFF、PDF、DOCX、XLSX、PPTX、TXT、Markdown、RTF、CSV、HTML、ZIP 和 WAV；
使用应用自有的小型有效样本，放在私有缓存的 discovery-samples-v1 子目录，不给未知类型伪造空文件。
最多复用原有两个查询进程，点击和当前菜单优先；不扫描用户文件，不执行样本菜单命令。
已有项目先显示，后续结果动态补齐；系统禁用项和不可控制的注册记录继续隐藏。
“更多”中的“检查文件”“检查文件夹”支持具体选择和多选，用于补充类型、版本库、网盘等专属菜单；
“管理”携带当前右键对象进入设置，选择只通过私有 IPC 临时传递。
注册目录扫描不依赖临时 Sample.txt，也不执行菜单命令。

设置按卡片分组并支持搜索；每批最多创建 8 行或工作 6 毫秒，之后让出 UI 线程，
后续批次由 16 毫秒计时器调度。位置例外控件只在展开时创建，类型专属行在名称下标注适用扩展名。
后台轮询按稳定身份增量更新，只新增、移除或更新真正变化的行，保留已有控件及展开状态。
首次出现可用项目后隐藏读取提示，其余发现继续在后台进行；轮询不会因十秒新鲜期结束而重启当前选择查询。
静态命令只有 verb、完整执行命令／处理器及参数一致时才合并显示，下面汇总各文件类型。
合并保留每个原始注册身份，原配置不同则显示“部分类型设置不同”；用户操作总开关或位置例外时，
才统一当前合并行中已发现的成员。后续新发现类型仍保留自身原配置，不自动扩大开启范围。
名称相同但命令不同、以及不能确认来源的动态根项不按名称合并。
目录与管理项缓存格式升级，旧格式自动回退后台发现，用户开关配置不改写。
页面可切换“按对象”“按应用”“按文件类型”视图；空白处分类提供前两种视图。
每个应用或后缀一张卡片，通用文件项和文件夹专属项单独成卡，不在每个后缀中重复。
视图切换和名称搜索复用内存目录，不触发 Shell 查询、注册扫描或磁盘读取。
卡片顶部总开关控制本卡片当前项目，部分开启时显示“部分显示”，关闭可统一隐藏；
位置例外仍有效，合并动作的全部成员在不同卡片和视图中共用原来的开关，不产生新配置身份。
检查文件、文件夹、桌面和手动刷新收进“更多”，主界面只保留分类、视图、搜索及开关卡片。

来源从注册 EXE／DLL 产品资料、打包应用身份和后台逐处理器查询的命令证据获取；
不能可靠归属的实际菜单放在“未识别应用”。规范命令名需要与来源查询结果匹配；无规范
命令名的传统项目需同时匹配图像、名称和完整已生成层级，名称相同本身不建立关联。
不同来源产生冲突证据时撤下应用归属，原操作开关身份及实际执行路径保持不变。
来源核对仅在设置检查后启动，与普通查询共享两进程上限，并为交互查询保留一个位置。
同一来源、注册版本及位置下已经检查过的菜单根身份不因样本路径或 Shift 再次检查；
出现新动作可补充检查。失败来源在本轮发现中暂时跳过，手动刷新或相关注册变化后允许重查。
来源核对只补充应用资料，不把处理器单独返回的项目加入菜单，也不执行其中的命令。
应用资料由宿主后台读取并缓存；命令包装器 rundll32 使用目标 DLL，无法确定实际来源的脚本
解释器保持未识别，网络模块不自动读取。设置与菜单仍共享宿主发现过程。

卡片总开关提交一次设置更新，仅捕获点击时当前卡片的成员；其他卡片、系统禁用项、另一
分类和后来发现的项目不会顺带更改，同一合并动作在另一卡片中的显示状态则随原规则同步。
菜单来源与后缀视图可通过设置搜索直接定位；所有语言的视图文案和指南同步更新。
目录缓存格式为 4，管理目录为 3，具体快照为 4；旧缓存回退发现，不修改用户开关配置。

动态来源查询只在管理发现的后台运行，占用至多一个共享辅助进程，普通菜单和执行仍优先，
两类任务合计最多两个进程。实际菜单先发布，来源检查不增加菜单项目、不保留执行令牌、
不调用命令；重复后缀共用已核对的菜单身份，进程异常来源本轮不继续自动尝试。
初始化依据 [IShellExtInit](https://learn.microsoft.com/en-us/windows/win32/api/shobjidl_core/nf-shobjidl_core-ishellextinit-initialize)，
查询依据 [IContextMenu](https://learn.microsoft.com/en-us/windows/win32/api/shobjidl_core/nf-shobjidl_core-icontextmenu-querycontextmenu)，
打包来源可读取 IExplorerCommand 的规范身份；这些探测结果仅补充系统实际菜单的来源资料。

使用指南位于常规页的“基础 → 右键菜单设置”，不在列表重复展示实现说明。

## 实际菜单与动态补齐

扩展直接显示在自绘右键菜单中，例如直接显示“7-Zip”，保留第三方级联，
不增加“系统扩展”包装层。扩展与“展开更多选项／管理”同组，位于菜单底部。
“管理”是该行右侧的独立按钮，鼠标和键盘可分别命中。
宿主已有的文件操作继续使用原有入口，避免重复项目和绕过应用的文件操作语义。

有缓存时立即显示快照，本次菜单内容保持不变，后台刷新供下次使用。
无缓存且用户已开启扩展时，立即显示应用菜单并后台查询；查询完成后可在本次菜单补齐。
补齐等待鼠标离开菜单项、按钮释放且级联关闭；沿用原菜单顶部、宽度和滚动位置，
到屏幕边缘后滚动，不重新定位整张菜单。Dock 上方菜单遵循原增长边界。
无可用扩展、失败或超时均不添加加载、失败或省略号占位；关闭菜单不取消有效后台查询。
扩展默认隐藏，因此发现成功也不会自动展示用户尚未开启的项目。

## 宿主服务与缓存

菜单与设置通过宿主统一服务共享目录、内存和磁盘缓存，私有设置 IPC 为 21；
组件公共 API、apiVersion 和 minHostVersion 不变。设置进程不单独扫描、查询或写缓存。
同一实际选择、场景和 Shift 状态的在途查询合并，最多两个查询辅助进程；
优先级为点击执行、当前菜单、当前选择预热、设置补充检查。
成功进程空闲五分钟回收；查询上限八秒，失败进程淘汰，自动查询按 2/4/8/最多 30 秒退避。

具体选择快照按完整键和最近使用记录淘汰：内存最多 64 条／16 MiB，磁盘最多 256 条／64 MiB，
单条最多 2 MiB、有效期 24 小时，普通和 Shift 桌面优先保留。目录单独持久化。已实际发现的管理根项另存 observed.dat，最多 1024 项／8 MiB；
只保存身份、范围、名称和图标，不保存实际选择路径、子菜单或令牌，不随具体快照淘汰或过期消失。
相关注册内容变化会使受影响管理记录失效；未知来源项目按已观察到的类型和位置判断依赖。
快照只保存文字、访问键、图标、状态和层级，不包含可执行令牌、COM 对象或原生句柄。
磁盘读写、目标属性检查和目录扫描在后台完成，损坏、过期和格式不符回退查询。
请求序号、相关注册依赖及对象身份防止晚到结果覆盖新记录；失败不清除有效快照，合法空结果可以更新。
无关注册变化保留已有快照；相关禁用、卸载和关联变化使对应记录失效。

启动预热只在用户开启扩展后进行；本地选择稳定 150 毫秒后可预热，网络路径不自动预热。
第三方首次查询仍可能较慢；内存命中不代表后台查询不再发生，也不保证扩展始终返回同一菜单。

## 隔离查询、图标与执行

实际项目来自真实 Shell 选择或背景的 IContextMenu；系统禁用和适用性由 Shell 决定。
辅助进程的标准输入输出接到 NUL，只通过私有管道通信。COM、原生命令与执行会话保留在
所属辅助进程和 STA；点击时重新核对身份及可用状态，消失、禁用或歧义项目拒绝执行。
显示快照里的旧编号不能作为命令使用。真实第三方命令只有用户点击后才执行。

沿用既有冷启动兼容处理：第一次成功聚合后再绑定实际对象一次，仍受同一次八秒期限约束。
首次文件夹查询的内部关联预热样本属于辅助进程兼容处理，不用来构建设置注册目录。
动态或自绘子菜单无法安全展开时回退原生菜单，省略号不单独成为自绘子项。

图标读取 MIIM_BITMAP、MIIM_CHECKMARKS 及回调位图；必要时只读加载模块资源，
以有界像素传输给宿主及设置页。沿用 7-Zip 小图标兼容，不修改第三方图标配置。
显式 & 访问键保留，唯一字母执行或展开，重复字母循环选中后回车确认；
搜索框输入、Alt 字母、禁用项跳过及中文输入法原始虚拟键处理沿用现有实现。

## 紧凑样式与滚动提示

Win10 深浅两种显式样式使用 11 DIP 字号、24 DIP 行高和 16 DIP 图标，左留白 8 DIP、
图标列 20 DIP、图文间距 6 DIP，右留白 8 DIP。面板圆角为 4 DIP，高亮圆角为 2 DIP。
尺寸随 DPI 缩放，其余样式与跟随系统的行为保持原有配置。

到达顶部时上侧箭头及分隔线隐藏，到达底部时下侧隐藏，中间位置两侧都显示。
两侧预留区保持稳定，避免隐藏提示时项目坐标变化或误点；隐藏侧不响应滚动提示点击。
