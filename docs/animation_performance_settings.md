# 动画与性能设置

首批设置集中在独立的“动画与性能”页，Dock 原页提供跳转入口。

| 设置 | 可选值 | 旧配置缺少字段时的默认值 |
| --- | --- | --- |
| 动画模式 | 跟随系统、始终开启、关闭 | 跟随系统 |
| 弹窗动画 | 关闭、淡入淡出、缩放 | 缩放 |
| 动画速度 | 快、标准、慢 | 标准 |
| Dock 悬停 | 不放大、单图标、邻项波浪 | 邻项波浪 |
| 悬停最大倍率 | 1.00～2.00 | 1.28 |
| 应用启动反馈 | 关闭、跳动、轻微缩放 | 跳动 |
| Dock 窗口最小化与还原 | 系统默认、缩放、淡入淡出、神奇效果 | 缩放 |
| 动画更新上限 | 自动、30、60、120 | 自动 |
| 系统节能时降低更新上限 | 开启、关闭 | 开启 |
| 电池供电时也降低更新上限 | 开启、关闭 | 关闭 |

## 行为范围

- “始终开启”覆盖 Windows 动画偏好，仍尊重单项关闭。“关闭”结束 SnowDesktop 管理的过渡和悬停放大，保留标题、窗口预览、点击操作和已保存的效果选择。
- 弹窗设置覆盖集合、Lua 组件面板和快捷导航的打开及关闭。设置改变时，正在关闭的面板完成关闭流程，正在打开的面板进入显示状态。
- 速度以基础时长乘以 0.7、1.0、1.4。宿主管理的声明式组件过渡与滚动文字也应用该偏好；Lua 的系统 `reducedMotion` 值和 `animation.requestFrame` 拒绝规则不变。详见组件 API 文档。
- 窗口效果只作用于从 SnowDesktop Dock 发起的最小化、还原；“系统默认”和兼容回退由 Windows 完成，不修改系统全局动画设置。
- 神奇效果使用窗口快照与 GPU 分条变形，沿 Dock 目标展开或收拢。无法取得可变形快照时采用兼容缩放；如果兼容画面也不可用，交回原生窗口操作。回退不修改用户选择。
- 浮动 Dock 的神奇效果同样优先获取快照。截图时临时排除自身上层窗口；系统无法排除时，短暂隐藏相交的自身窗口并同步恢复，不改变 Dock 唤出状态。快照最多保留 16 个窗口且总计不超过 96 MiB，优先保留仍最小化窗口；没有缓存的原生最小化窗口仍可能使用兼容缩放。诊断日志记录请求效果、实际效果、快照来源与回退阶段。
- 窗口效果呈现期间，与效果窗口相交的已显示独立 Dock 内容与背景保持在效果之上，结束后恢复正常桌面或浮动层级；其他显示器上不相交的 Dock 保持正常层级。嵌入桌面回退路径按面板、放大图标及标题区域裁切效果。
- 更新上限控制宿主逐帧更新和组件共享动画唤醒。原生合成器仍沿自己的时间轴呈现，因此它不是 Windows/DWM 的全局帧率上限。降频继续按真实时间推进。
- 节能策略将更新上限限制为 30，不更换效果。命名业务定时器和数据源采样规则保持原有行为；合并后的画面刷新可能在下一动画更新时提交。
- 设置修改即时生效；悬停倍率拖动会合并宿主更新，并在拖动结束、短暂空闲或离页时保存。

## 验证范围

自动化测试覆盖配置默认值与持久化、IPC 往返、模式与节能策略、时间轴、悬停布局与命中边界，以及神奇效果四方向几何。标准构建和测试结果记录在对应提交中。

桌面宿主动效需要实机验收：三种全局模式、各弹窗效果、1.0/1.28/2.0 倍悬停、四侧及浮动 Dock、混合 DPI、多屏目标、连续最小化/还原、动画播放中关闭或切换效果，以及窗口快照失败时的操作结果。本轮还需验证图标与预览卡两种入口、四个窗口依次最小化后还原、无缓存还原、Dock 背景与溢出图标遮挡，以及捕获隔离时 Dock 是否闪烁。设置页检查键盘操作、窄窗口、深浅色和高对比度。编译或规则测试通过不等于这些场景已验收。

第二批预留全屏策略、悬停影响范围、预览延迟和 Dock 唤出/收起效果。唤出/收起选项仅在“仅在唤起时显示 Dock”开启时允许调整；关闭该模式后保留已选值。
