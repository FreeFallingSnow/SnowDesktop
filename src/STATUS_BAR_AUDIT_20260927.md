## 4. 既有需求复核与最新产品边界

- 栏体仍只支持顶部／底部。靠边同侧自动将状态栏控件并入 Dock，无合并开关；中央保留 Dock 输入。融合的常驻／仅唤起模式由 Dock 决定，常驻模式必须预留位置，菜单交互期间暂时保持，关闭恢复策略；岛式与独立栏分别避让。
- 左侧系统菜单、搜索和默认关闭的定宽资源信息；独立栏日期居中，通知紧邻右侧。融合时搜索只留 Dock，时间两行与通知位于整栏最右端，其余控制和托盘在其左侧；Dock 放大与名称沿用原设置。音量滚轮和三部分独立提示继续保留。
- 常规右键只有状态栏设置、任务管理器；左侧菜单电源动作保留二次确认。不增加右键主题、左右状态栏、自有通知历史或任意 Lua 状态栏布局。
- 独立栏体跟随全局主题，独立预设／自定义及无窗口／最大化场景覆盖留在状态栏设置；主题与材质页只保留跳转。融合栏体跟随 Dock，自有弹窗使用弹窗主题。设置分组、路由兼容、搜索和十种语言保留。
- 除设置外使用原生绘制；面板与提示复用原生输入／UIA／材质／动画。单一控制面板、标题齿轮、独立单行媒体条、没有独立静音设置、边缘单边描边均保留。离屏检查不能证明桌面玻璃合成效果。
- 托盘协议模块独立于任务栏美化，保留固定／排序拖拽、图标增删改、代次恢复、v4／旧版回调及有限菜单纠偏。YASB 固定提交 `d6d1e6d553b0` 的参考来源和 MIT 许可在 `third_party/yasb/`、关于页及相关说明保留。

## 6. 尚不能关闭的原场景

| 项目 | 未关闭原因／需要的证据 |
| --- | --- |
| 高频通知开关、弹窗切换与全屏 Dock | 已消除代码中确认的重入与过期请求风险；仍需最终二进制连续操作确认不挂起、正常关闭且不抢焦点 |
| 微信／PowerToys／WPS／抖音 | 原应用各自菜单实现与隔离夹具不同；需核对右键／单击、顶部越界、保持与拖拽 |
| 某屏只占位不显示 F21、混合 DPI／热插拔 | 已有恢复及几何／HRESULT 诊断，原问题根因尚未取得明确证据 |
| 真实无线／蓝牙／音频／亮度、充电与限充 | 自动测试替换了设备边界；需要真实设备操作及实际结果对照，同步驱动永久阻塞不由取消标志解决 |
| AMD 约 90% | 缺问题机原始 PDH／分引擎样本与同时段任务管理器对照，不能标作校准完成 |
| 旧约 400 MiB 与鼠标卡顿 | 已有 dump 未捕获确定的持续主线程死锁；没有同场景前后内存证据，不将本轮清理改动当作已证明根因 |

桌面宿主不使用自动化操作冒充验收，遵守仓库实机规则。公共 Lua 新任务保持 API v2，组件需 `minHostVersion: "1.0.8.0"` 并检测新增 feature；同版本早期构建不能按版本号猜测能力。尚未发布依赖这些接口的社区组件。
