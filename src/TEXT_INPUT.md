# 桌面文本输入

`text_input_state.h` 提供 UTF-16 字符边界、词移动和普通文本撤销历史。
`text_input_window` 提供内部消息窗口与 DirectWrite/D2D 编辑器，窗口类为
`SnowDesktop.DrawnTextInput`。它支持迁移所需的一组 EDIT 消息，但不是原生 EDIT。
`text_input_accessibility` 提供动态 Value、Text 和文本范围查询。

| 承载入口 | 呈现与结束规则 |
| --- | --- |
| 日程标题、备注与控制中心网络字段 | 消息窗口放在屏幕外，由系统面板在同一次合成提交中绘制。标题 Enter 提交；备注保留换行，Ctrl+Enter 提交；Tab 切换字段，Escape 由面板取消 |
| 快捷搜索、逻辑槽选择器搜索 | 面板内绘制，原搜索任务链路接收文本及当前组合文本。方向键、Enter 和 Escape 继续遵循原搜索规则 |
| 桌面、集合、文件夹、Dock、快捷导航重命名 | 自绘浮层允许视觉折行，逻辑单行；粘贴换行转为空格。保留 RenameController 目标、会话编号、扩展名初选区、工作区锚定和 Shell 队列；Enter 提交，Escape 取消，符合原策略的失焦提交 |
| Lua 系统确认表单 | 普通输入和受保护输入复用共享编辑器，安全类型通过自绘菜单选择；确认与取消保留原请求生命周期 |
| Lua 文本控件、集合搜索、菜单输入 | 保留原绘制承载，接入共享字符边界与撤销历史，继续遵循原存储和事件链路 |
| 遗留 Lua 内联桥 | 未注册公开入口，保留兼容适配，编辑窗口也使用共享自绘类 |

普通输入支持完整代理对、组合附加字符、常见 ZWJ emoji、旗帜和 CRLF 边界，
没有宣称覆盖完整 Unicode UAX #29 的所有文字规则。菜单沿用 GDI 呈现，其复杂
双向文字命中仍受原后端限制；新的共享窗口使用 DirectWrite 范围和命中。

相同模型值回显保留光标和历史。组合期间真正的新模型值与选区延后应用，
不会另发用户 change。组合提交作为一次撤销操作，结果与随后字符消息去重。
原生 IMM 继续承载系统候选窗口；Microsoft 拼音、第三方输入法和 TSF 扩展场景
必须分别实测，自动消息检查不能替代这些兼容性验收。

Lua 的 `view.textInput`、`view.textArea`、`view.searchBox`、`view.numberInput`、
`control.textInput` 和 `control.textArea` 不改变参数或 UTF-8 选区单位。
新的编辑快捷键与模型协调行为属于宿主实现变化。当前 `apiVersion` 不变；
组件若依赖这些行为，应声明包含本实现的 `minHostVersion`，同版本早期构建
不能仅由版本号推断具有新行为。

密码使用独立缓冲，替换和释放时擦除。普通值、显示缓存、历史与 Text provider
不持有密码；Value provider 标记 IsPassword 并拒绝读写，复制与剪切禁用。
可信提交只能调用 `CopySecret`，调用方负责擦除接收缓冲并沿用既有受保护请求。
密码输入禁用 IME，允许粘贴；预览与日志禁止采集明文。

UIA 回调通过窗口线程获取当前状态，带有会话身份，销毁后拒绝旧范围查询。
嵌入输入提供逻辑几何，范围矩形按真实 DirectWrite 布局和宿主裁剪得到。
窗口测试使用独立隐藏 fixture；系统面板离线检查使用同一生产 renderer。
桌面黑闪、候选窗口位置、读屏体验及所有重命名承载面的实际表现由实机验收确认。
