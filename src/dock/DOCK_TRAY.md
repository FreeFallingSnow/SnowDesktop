# Dock 托盘恢复

托盘恢复名单按 EXE 文件名或完整路径匹配。用户选择的单击、双击是发送给原托盘图标的操作，不能推断任意托盘图标点击都能打开主窗口。

名单的默认项是 QQ、微信的两个 EXE 名称和飞书。多实例使用原托盘图像和原始悬浮提示，不能按昵称、账号或提示内容推断身份；回调绑定到图标身份和进程所有者，并在执行前重新核对。

Dock 自身的单击、双击启动设置决定单实例的触发时机；多实例单击打开 Dock 选择弹窗。已经具有可操作窗口时沿用 Dock 的窗口操作。新启动按钮保留原快捷方式的启动行为。

列表复用集合/Dock 弹窗的独立合成表面、材质、定位、开关动画及点击外部关闭流程。提示文本按原文换行；图标和进程所有者来自当前托盘快照。列表更新不得把按下或键盘焦点绑定到另一个账号。

经典托盘初始读取直接复制工具栏文本；现代快照可以补齐已有图标的未知提示。显式为空的实时提示、已协商的回调版本和所有者不能被后续补充覆盖。

启动器身份保留快捷方式原目标。后台身份解析依据启动器产品元数据、同一安装根、直接子目录中的同名程序及一致的产品/公司信息建立运行别名，覆盖安装目录同时保留多个版本的情况。此规则没有应用品牌表；缺少证据、读取失败或链接目录不产生别名。已有父进程关系、应用 ID 和 Squirrel 匹配继续生效。
