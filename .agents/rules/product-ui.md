# 产品界面规则

适用于设置页、共用编辑器、内置组件界面、高级功能入口及应用菜单。本地化按 [根规则](../../AGENTS.md#公共契约与本地化)，验收按 [构建与验证](validation.md)。

## 高级功能入口

分别核对 Steam 桥兼容可用性与功能解锁状态，菜单、跳转和实际执行使用同一判断。状态变化后刷新入口，执行修改前再次检查。

| 状态 | 正向入口与执行 |
| --- | --- |
| 无兼容桥 | 隐藏创建、启用、配置入口，包括菜单、设置导航、搜索和快捷操作；直接调用也拒绝打开编辑器 |
| 有桥未解锁 | 保留入口，点击统一跳“常规 → 高级功能”，提示条显示对应语言的“请解锁后启用高级功能”；已有对象的设置入口也直接跳转，编辑与执行保持受限 |
| 有桥已解锁 | 正常入口和操作，继续遵守目标、数据与权限约束 |

  > 例如，无桥时从菜单移除“启用大图标”；有桥未解锁时，点击该项进入解锁页并显示提示。

- 反向操作始终可见可执行：恢复普通图标、关闭效果、撤销配置。失去桥或解锁时保留已有配置、资源、布局和显示，由用户选择退出功能。
- 常规页的解锁卡片按渠道显示：便携版无桥未解锁时，原按钮位置显示“解锁”，点击 Steam 商店；安装版同条件隐藏卡片与搜索项。有桥或已解锁时显示相应状态。
- 验证无桥、有桥未解锁、有桥已解锁，以及失去桥/解锁后的反向操作。复用已有检查，核对可见行为和数据；桌面菜单按 [实机规则](validation.md#实机验收) 验收。

## 设置行与留白

- 新增/调整 WinUI 行复用 `SettingRow`、`InitializeSettingsGroup`、`StyleSettingsSubrow` / `UpdateSettingsSubrows`，沿用同组标签左边距、控件右边距、行高及必要的高度覆盖。控件经共用行样式处理后加入卡片。
- 条件行在设为 `Collapsed` 前完成样式，或在显示路径补齐。`UpdateSettingsSubrows` 跳过隐藏行，须逐一核对后续显示时的 padding、分隔线和最小高度。
- 提交前检查标签左边线、开关/按钮/输入框右边线、行高及分隔线，包含初始隐藏后显示的行。开关和状态文字均位于卡片内侧留白，保持完整可见。
- 视觉截图包含调整行、至少一条同组相邻行和完整左右卡片边界。按涉及宽度、DPI、文案长度检查折行、裁切、留白；无法取得可靠证据时记录待验证。

  > 例如，发现子行贴边时，先检查共用 `Padding` 是否初始化，再核对该行所需间距。

## 设置说明

- 全面排查时逐项评估所有设置，包括无说明项、动态字段和条件项；记录名称、原说明、保留/精简/合并/按需展开/删除结论、理由及实现，按独立设置计数。
- 默认依靠标签、选项、数值、单位、预览及状态表达用途；标签含糊先改标签。说明只补用户决策缺少的适用范围、联动、前提、限制、输入格式和实际后果，保留数据范围及权限影响。
- 对照真实绑定、执行、持久化及生效逻辑核实文案。分类规则修改后立即应用；字体等需重启的设置明确生效条件。按状态显示适用信息，默认值交给控件和恢复默认操作，留空含义等输入语义放在输入附近。
- 面向用户写结果与动作，使用其作决策所需的术语。多项共用信息在组内说明一次；关键后果放在操作附近，高级语法、完整规则及参考资料按需展开，必要时给输入格式短例。

  > 例如，字体设置写“重启 SnowDesktop 后生效”；Explorer 重启写“桌面和任务栏会短暂消失”。删除“拖动滑块调整数值”等重复常规操作的说明。

- 删除文案时同步清理说明控件、空容器、无效按钮、状态栏、事件和专用边距。共用行统一更新可见说明及 UI Automation 说明；空文字保持折叠，搜索定位只指向有效可见控件，保留有效操作及恢复默认能力。
- 文案修改同步全部语言与英文回退，检查实际入口、折行、留白、辅助说明及交互；按影响选择检查。

参考：[Microsoft 写作](https://learn.microsoft.com/en-us/windows/apps/design/style/writing-style)、[Microsoft 提示](https://learn.microsoft.com/en-us/windows/apps/develop/ui/controls/tooltips)、[Apple 帮助](https://developer.apple.com/design/human-interface-guidelines/offering-help)。

## 设置图标

- 导航与页标题使用 Microsoft Fluent System Icons 官方 SVG，同语义、同原生尺寸的 Filled 与 Regular 叠加，保持原轮廓、圆角、比例。沿用当前配色，以 Filled 作色块、Regular 作轮廓。
- 选直接表达功能的图标，复用同一资源；保留高对比度的系统字形回退。仅调整颜色，不改路径几何；不混用弃用 Color 变体或分发 Filled 字体。
- 固定上游版本与内嵌 Regular 字体一致，以 `THIRD_PARTY_NOTICES.md` 和 `assets/settings/icons/README.md` 为准。每个 SVG `metadata` 记录名称、尺寸、组合及提交，资源变化同步映射表并保留 MIT 许可。
- 检查浅深背景、实际导航/标题尺寸，与相邻图标比较轮廓清晰度和视觉重量。用户要求先预览时，提供独立候选、浅深效果和界面尺寸，确认采用后才替换源码/构建资源，再完成应用内验收。

  > 例如，“页面与网格”使用 `Table Multiple 24 Filled + Regular`，同时表达页面与网格。

## 右键菜单

- 新菜单（含右拖动作菜单）复用 `PrepareMenuIconsForPoint`、`SetMenuItemIcon`、`ShowModernMenu`、`ClearMenuIcons`，沿用共用样式、渲染、弹窗、消息循环、主题、DPI 和图标体系。移动、复制、链接、取消等操作配语义图标。
- 共用生命周期处理外点关闭、Esc 取消、焦点和层级恢复；桌面、Dock、浮动弹出面等无激活宿主点击也须关闭菜单。关闭仅取消当前菜单，保留仍待决策的拖放上下文，禁止执行未选动作。
- Shell 系统菜单使用其原有交接边界；应用新增能力接入共用设施。
