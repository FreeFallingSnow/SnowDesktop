# 本地协作构建看板

第4版协调协议把当前编辑窗口与已捕获的候选分别展示。候选列表显示任务、排队原因、Run与源码摘要，
可打开对应批次检查日志和验证；旧候选完成不会替换新窗口。运行记录列出已保存的产品或测试文件及清单摘要。
服务只投影协调器与Run记录，不另建调度状态，不输出候选绑定中的执行nonce。

页面以任务列表和待处理项为主。任务可按名称、文件、测试与状态筛选，直接显示等待原因、检查时间和计划摘要；长路径与证据按需展开。执行区分别显示已选、已执行、通过、失败、未运行、跳过、无结果记录和重试后通过，不能用已选数量代替执行结果。逐测试结果附实际耗时；尚未采集的编译分段时间不估算。

逐项证据分别显示测试执行、输入身份、编译依赖、运行时文件端点和实际模块观察；已采集不表示依赖闭合，文件起止一致不表示连续观测。
原始尝试、输入及报告摘要按需展开。缺少记录显示未记录；模块观察改变计时时明确提示不能直接与普通执行比较。
批次与独立补验共用这份投影。依赖原因最多展示12项并注明省略数，文本做凭据赋值遮盖，前端按文本显示。

日志支持文本与错误/警告筛选，范围仅为当前保留的尾部。历史可按结果筛选，登记撤回且没有执行开始记录时显示“登记撤回 · 未构建”。自动刷新保留筛选、详情、日志暂停和滚动位置；任务筛选也随本地偏好保存，日志正文不进入本地存储。

直接打开 **http://127.0.0.1:8765/**。`scripts\build.bat` 的写/执行协作命令自动确保服务运行（status 仅只读，不启动服务）；关闭网页不会停止构建。服务没有登录启动项，电脑重启后第一次协作命令会重新启动它。

看板只监听 `127.0.0.1`，复用现有 Python 3.8+ 标准库。没有依赖安装、外部托管、下载、自动浏览器弹窗或防火墙修改。

```bat
scripts\build-dashboard.bat status
scripts\build-dashboard.bat stop
scripts\build-dashboard.bat start
scripts\build-dashboard.bat start --port 8766
```

双击 `scripts\build-dashboard.bat` 也可启动。端口冲突时拒绝启动，不终止未知监听者；协作构建不会因为看板不可用而失败。手动停止只通过已核对实例 nonce 的本地请求文件通知自身服务，完全独立于构建进程。

成功启动或确认已有服务后，将首选端口原子保存到本检出的 `.build/dashboard/preferred-port.json`；
后续自动入口和未指定 `--port` 的管理命令使用该端口，没有记录时仍使用 8765。隔离检出应先显式
选择自己的空闲端口，避免在主面板停用时占用它的端口。无效或链接的偏好记录不会静默换回另一端口；
保留记录并显式选择 `--port`。status 不写回偏好，网页查看偏好仍只保存在浏览器。

协调入口先用新鲜回执与固定 loopback 健康响应核对实例，整个 HTTP 请求最多 750 毫秒、响应最多
4 KiB，禁用代理、重定向和默认凭据。匹配时不启动 Python；没有看板入口文件时也不探测 Python。
回执异常、实例不同或服务停止时仍进入原管理入口，不停止未知服务。Windows 启动尝试使用当前
Job 允许的 breakaway，调用方退出后服务可继续运行；父 Job 拒绝时保留其限制，服务寿命仍受该 Job 约束。
这不改变编译进程的私有 Job、取消和输出租约。

## 数据与限制

- 只读 `.build/collaboration/` 下固定的状态、结果、覆盖、问题交接与日志文件；没有 HTTP 写操作、命令执行、任意路径读取、环境变量枚举或跨域权限。
- 当前批次、编辑修订号、重开编辑、检查与占用观察、冻结输入 SHA-256、实际测试进度、请求与覆盖关联、失败交接和历史结果分别展示。
- 检查中、失败或中断保持屏障；陈旧登记年龄不等于进程死亡或修改完成。未登记的会话与尚未登记的新 `begin` 等待者无法完整获知。
- 历史结果是历史快照；HTTP 轮询不会重新散列整个仓库，也不会将历史通过声明为当前源码通过。`finish/wait` 复用历史通过时另行验证内容和已记录的二进制身份。
- 构建与链接阶段从日志推断，并行阶段可能交错。CTest 报告 `N/M Test` 后才显示测试计数；不存在假百分比。链接输出数量只是已观察到的下界。
- 状态缓存 2 秒；日志每次最多新增读取 256 KiB，最多显示最近 180 行。超长旧日志从尾部开始，明确标记省略；错误和敏感键赋值做有界显示与遮盖，这不是完整的任意文本脱敏器。
- 元数据和日志在 Windows 使用 `FILE_SHARE_READ|WRITE|DELETE`，避免监控读取挡住协调器的原子替换。拒绝 reparse point、路径穿越、外部 Host/Origin、跨站访问与写入方法。页面只用 `textContent` 显示任务和日志，配置 CSP。
- 本地 HTTP 服务没有用户认证。能够以当前用户修改协作状态的程序也能伪造记录；看板不是安全边界或不可篡改审计系统。

## 验证

```bat
scripts\test.bat name "^build_dashboard$"
scripts\test.bat name "^build_dashboard_browser$"
```

测试由现有 C++ 原生驱动执行。上面的标准选择入口用于没有活动协作批次时；协作期间在本任务计划中声明 build_dashboard、build_dashboard_browser 并等待共同结果，不绕过共享构建权限。浏览器条目需要显式选择，使用已安装 Edge 的独立 headless profile，不控制用户浏览器。HTTP 和浏览器使用独立端口及醒目标明的模拟数据，覆盖文件共享、元数据与日志边界、实际测试计数、PowerShell 七位 UTC 小数时间戳、筛选和查看偏好、长等待列表与窄窗口；截图和证据保存在驱动输出的夹具目录。

原 PowerShell 看板启动器在开发中被安全软件以 `HEUR:TrojanDownloader/PS.NetLoader.ae` 删除，未恢复、未加入白名单。启动入口仍为 `manage.py`；协调器的新增健康检查仅请求固定 loopback 地址，不下载或执行网络内容，没有更改防护设置。历史事件不被当作“已证明误报”。

界面使用亮色主题，页面与标签图标复用 `assets/icon/icon.png` 的实际软件图标。等待与构建不调用大模型；桌面回合完成通知由 Work 设置管理，本地批次完成不会自动唤醒原对话。


看板继续使用亮色主题和 `assets/icon/icon.png` 软件图标。写/执行协作入口自动确保，status 不启动，访问 http://127.0.0.1:8765/。
新增“本地等待”显示票据条件、状态、截止与恢复入口；等待进程退出不完成编辑登记。
失败续修显示逻辑批次和第 N 次执行，并可查看上一失败尝试；历史失败不会被后续成功覆盖。
自动重试显示原计划数量、失败次数、首次/最终原因及逐次日志；通过后仍保留 flaky 标记。
关闭网页不终止本地等待/构建。HTTP 仍仅只读、仅本机，无任意路径/命令或写入入口。
票据完成不会自动恢复 Work 对话；恢复写入须重新通过 begin/claim，不能把面板可用窗口当编辑授权。

页面会记住各批次详情的展开/折叠状态、日志暂停和滚动位置；历史批次选择保存在网址中，刷新后继续查看同一批次。偏好仅存在浏览器本地，不更改协作登记；日志内容不写入本地存储。浏览器拒绝存储时，本页自动刷新仍保留展开状态。

默认使用 `ready-and-wait/watch wait` 保持当前对话工具进程活动，条件满足后由工具返回继续；后台票据只是显式无人值守选项。看板中完成任务的文件列表表示来源记录，后续任务可接手；活动编辑者的声明表示当前编辑占用。共享语言条目按脚本说明使用串行比较写入，不要求原会话同意。冻结保护仍覆盖所有文件。

“本地等待”卡片可折叠；展开列表最大高度 400px（窄窗 320px），在卡片内滚动。
运行记录单独显示资源统计状态与采样时间。Run 通过但只有过程采样时标为“不完整”，CPU 与内存标注为最后采样；无法取得 Job 统计时不将占位零值显示为有效用量。缺失记录与旧格式的未知状态分别展示，不能据此推断构建失败或成功。
验证区可展开逐条测试证据，核对请求任务、原始 Run、输入/二进制/命令/环境摘要；未知依赖不显示为已自动复用。
人工验收另列任务需求修订、条件、运行文件、反馈引用及独立区间。没有活动批次时仍可查看已有验收；
独立补验的“引用既有结果”另列请求任务、核对时间、原 Run、测试及摘要；校验独立凭据与原记录完整性。
引用不增加执行或通过计数，也不修改原 Evidence；缺失、损坏或不匹配的凭据显示不可核对。展示的是核对当时的记录，不授予当前编辑或复用权限。
旧记录不补造字段，跨重启或时钟不可用时不计算假耗时。人工通过不计入 CTest 通过数。
自动刷新、增删票据和手动刷新保留展开与滚动偏好；列表缩短时浏览器将滚动位置限制在有效范围。
偏好只存浏览器本地，禁用存储仍保持当前页面状态。服务继续只读 loopback，无构建/取消任务按钮、
公网发布、登录自启动或安全设置修改。亮色软件图标与现有布局保持。
